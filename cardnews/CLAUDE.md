# 카드뉴스 제작 (인스타 매거진)

이 폴더는 **앱과 분리된 콘텐츠 제작 라인**이다. `src/`의 앱 코드와 무관하며
`package.json`도 여기 것(Playwright 캡처 전용)을 쓴다.

## 절대 규칙

1. **브랜딩은 앞뒤 표지에만.** 커버 마스트헤드 `RIVEA MAG` + 마지막 아웃트로 1장.
   본문 카드에는 브랜드를 넣지 않고, 구매 링크·판매 유도는 어디에도 넣지 않는다.
2. **디자인은 `style.md`가 단일 기준.** 회차마다 다시 정하지 않는다. 바꿀 게 생기면 `style.md`를 고친다.
3. **이미지 생성 AI로 카드를 만들지 않는다.** HTML/CSS로 만들고 Playwright로 캡처한다.
   (이유: 1px 단위 제어 가능, 템플릿화하면 몇 장이든 동일 퀄, 비용 0)
4. **사진은 Unsplash / Pexels만.** 큐레이션 사이트(핀터레스트·cosmos 등)는 원본 권리 불명확 → 금지.
5. **타 브랜드 로고·라벨이 읽히면 크롭으로 제외.**

## 폴더 구조

```
cardnews/
├── CLAUDE.md            이 파일
├── style.md             디자인 단일 기준 (컬러·타이포·레이아웃·사진 규칙)
├── package.json         Playwright (앱 의존성과 격리)
├── capture.mjs          HTML → PNG 캡처
├── measure.mjs          카드별 하단 여백·오버플로 검사
├── veilcheck.mjs        텍스트가 베일 유효구간 안에 있는지 검사
└── episodes/
    ├── 260803_백세시대/      v1 (인물 사진 + 흰 본문 카드) — 참고용 보관
    └── YYMMDD_주제/          v2 표준 (사진 배경 + 최소 텍스트)
        ├── index.html   8장 카드 (section.card 하나가 1장, 마지막은 브랜드 아웃트로)
        ├── img/         raw-*.jpg(원본, 재크롭용) + 그레이딩된 최종본
        ├── out/         card-01.png ~ card-08.png  ← 업로드할 결과물
        ├── caption.md   인스타 캡션 + 해시태그 + 첫 댓글
        └── sources.md   이미지 출처·라이선스 기록
```

## 새 회차 만드는 순서

1. `episodes/YYMMDD_주제/` 생성. 직전 회차의 `index.html`을 복사해서 시작한다.
2. **사진 고르기 — 반드시 눈으로 보고 고른다.**
   Pexels/Unsplash 검색 결과에서 후보를 내려받아 **컨택트 시트로 합쳐 실제로 확인**한다.
   alt 텍스트만 믿고 고르면 안 된다 (검색어가 `mature`여도 70대 다큐멘터리 컷이 대부분 나온다).
   - **인물보다 정물·텍스처·빛.** 밝은 웜톤(아이보리/베이지)으로 통일하면 저절로 한 세트가 된다.
   - **텍스트 앉힐 빈 영역이 있는지**를 최우선으로 본다. 꽉 찬 사진은 예뻐도 못 쓴다.
3. **1080×1350으로 크롭 + 통일 그레이딩** (`style.md` 5항 수치 그대로). 전부 세로 풀블리드다.
4. 본문 작성. 카드에는 **라벨 + 헤드라인 2줄 + 성분 1줄**만. 이유·수치·주의는 전부 `caption.md`로.
   수치는 단정하지 말고 "~로 알려져 있다".
5. `node measure.mjs` + `node veilcheck.mjs episodes/YYMMDD_주제` — OVERFLOW 없고, 전 카드 베일 OK여야 한다.
6. `node capture.mjs episodes/YYMMDD_주제` — `out/`에 PNG 생성.
7. **결과 PNG를 컨택트 시트로 만들어 직접 확인.** 캡처만 하고 끝내면 텍스트 겹침을 놓친다.
8. `caption.md`, `sources.md` 작성.

## 자주 났던 실수

- **베일을 진하게 깔면 사진이 크림색으로 뭉개진다.** 처음 .93/.86으로 했다가 사진 분위기를 다 죽였다.
  → 기본 .68/.46. 어두운 사진만 `.deep`. **사진이 배경으로 보여야 한다.**
- **페이지번호가 밝은/질감 있는 배경에서 사라진다.** → 옅은 아이보리 받침(4px) 필수.
- **텍스트 위치를 억지로 통일하지 말 것.** 피사체가 위쪽인 사진은 `.txt.bot`으로. 사진과의 관계가 통일보다 우선.
- **카드에 설명을 넣기 시작하면 스와이프가 멈춘다.** 늘리고 싶어지면 캡션으로 옮긴다.
- **`measure.mjs`는 카드 구조가 바뀌면 셀렉터를 못 찾고 죽는다.** `.content`/`.over`/`.txt` 순으로 찾는다.
- **zsh는 따옴표 없는 변수를 단어분할하지 않는다.** `for id in $IDS`, `set -- $kv`가 조용히 깨진다
  → `printf '%s\n' ... | while read a b` 사용.
- **`.card img{position:absolute;inset:0}`은 배경 사진만 잡아야 한다.** 그냥 두면
  팔로우 카드 아바타 같은 **중첩 이미지까지 배경으로 깔려** 좌상단에 떠버린다.
  → 반드시 **`.card > img`**(직계 자식)로 한정한다.
- **제품 카드 사진은 피사체가 소스 중앙에 있으면 크롭으로 못 피한다.**
  제품명·확인 줄이 어두운 피사체 위에 얹혀 안 읽힌다 → **사진을 교체**하는 게 빠르다.
  피사체가 하단에 있고 상단이 빈 컷을 고른다.
- **Pexels/Unsplash 검색은 curl로 안 긁힌다** (클라이언트 렌더링). 브라우저 도구로 `img` src에서 id를 추출한다.
