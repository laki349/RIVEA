# 카드뉴스 레퍼런스 (조사: 2026-08-05, 인스타 로그인 상태에서 실물 확인)

> 이 문서가 생긴 이유: `style.md`에 레퍼런스가 **"@glowupmag (31만)" 한 줄**뿐이었다.
> 그건 레퍼런스가 아니라 정황이다. "모호하다"는 지적이 정확했다.

---

## 1. 레퍼런스가 모호해지는 이유와 해법

**모호한 레퍼런스**: "@glowupmag 느낌으로 가자."
→ 뭘 가져오는지가 없다. 사진? 타이포? 카피 톤? 카드 수? 캡션 분담?
→ 만드는 사람마다 다르게 해석하고, 회차마다 흔들린다.

**해법 — 차원을 쪼개고, 차원마다 레퍼런스를 딱 하나씩 지정한다.**
카드뉴스는 최소 5개 차원으로 분해된다.

| 차원 | 무엇을 정하는가 |
|---|---|
| ① 포맷/구조 | 몇 장, 카드당 텍스트량, 카드↔캡션 역할 분담, 반복 프레임(라벨·워터마크) |
| ② 시각 언어 | 컬러·타이포·사진 종류·그레이딩·텍스트 정렬 위치 |
| ③ 콘텐츠 뼈대 | 무엇을 근거로 말하는가 (성분? 리뷰? 가격? 트렌드?) |
| ④ 톤&보이스 | 말투, 독자와의 거리 (선언형? 대화체? 에디터 1인칭?) |
| ⑤ 커머스 전환 | 콘텐츠→발견→구매를 어디서 어떻게 잇는가 |

**그리고 차원마다 "가져올 것"과 "버릴 것"을 같이 쓴다.**
버릴 것을 안 쓰면 레퍼런스가 통째로 복사되고, 그게 표절처럼 보인다.

> 실제로 이번 조사에서 가장 유용했던 건 "좋은 레퍼런스"가 아니라
> **반례(anti-reference)** 였다. 올리브영 매거진은 포맷은 훌륭하지만
> 비주얼은 우리가 절대 하면 안 되는 방향이라는 게 명확해졌다.

## 2. 레퍼런스 후보 5 + 예비 1

숫자는 2026-08-05 직접 확인.

### 후보 A — @glowupmag · 팔로워 31.4만 / 게시물 1.2만
**담당 차원: ① 포맷/구조 (현재 우리 v2의 원본)**

실물 해부 결과:
```
[매 장 공통 프레임]
좌상단  ▪ 카테고리   (Item / Place / Others / Cinema …)
우상단  glowup magazine   ← 워터마크가 매 장에 들어간다
하단좌측 텍스트 블록 (좌측 정렬 고정)
        흰 텍스트 + 하단 다크 그라데이션

[커버]
한글 헤드라인 2줄 (큼)  →  영문 제품/주제명 (더 큼, 화면 밖으로 잘림)
예) 자기, 차 냄새 좋다 / "마르지엘라니까"
    Maison Margiela Car Diffuser

[본문 장]
"큰따옴표로 감싼 한 문장"  ← 크게
설명 1~2줄               ← 작게
예) "레이지 선데이 모닝 향입니다"
    마르지엘라가 선택한 첫 번째 카 디퓨저 향
    프레그런스의 시그니처 '레이지 선데이 모닝'이다

[리듬]
8장 구성. 중간중간 **텍스트가 아예 없는 순수 사진 장**을 섞는다.
사진 위에 작은 플로팅 라벨(Fragrance / On the Go)로 대상을 지목한다.
```
- **가져올 것**: 매 장 공통 프레임(카테고리+워터마크), 큰 인용문 + 작은 설명 2단 구조,
  텍스트 없는 사진 장을 섞는 리듬, 캡션 끝에 출처 표기(`📷브랜드`), 해시태그는 별도 댓글.
- **버릴 것**: 흰 텍스트 + 다크 스크림(우리는 잉크+아이보리), 하단 좌측 고정 정렬,
  영문 제목을 프레임 밖으로 자르는 크롭(우리 독자층엔 불친절).
- ⚠️ **주의**: 좋아요가 게시물당 150~1,500개. 31만 팔로워 대비 약 0.4%다.
  게시물 1.2만 개 = **물량으로 도달을 만드는 운영**이다. 팔로워 수만 보고
  "콘텐츠가 훌륭하다"고 결론내면 안 된다. 우리는 물량을 못 따라가므로
  **장당 완성도로 가야 한다.**

### 후보 B — @oliveyoung_magazine · 팔로워 14.3만 / 게시물 950
**담당 차원: ③ 콘텐츠 뼈대 + ⑤ 커머스 전환 / 동시에 ② 시각 언어의 반례**

- 커머스(올리브영)가 직접 운영하는 매거진. 우리와 사업 구조가 같다.
- 게시물 950개로 14.3만 — glowupmag의 **1/12 물량으로 절반의 팔로워**.
  선별형 운영이 가능하다는 증거. 우리가 따라야 할 쪽은 이 모델이다.
- 반복 포맷이 명확: `요주의 신상`(주간 신상), `A VS B 비교`, `○○ 필수템`, `루틴`.
- **가져올 것**: 반복 코너 이름을 만들어 시리즈화, `VS 비교` 포맷,
  주간 정기 코너, 선별형(저물량·고완성도) 운영.
- **버릴 것 (중요)**: 비주얼 전체. 형광 핑크/블루 마커 텍스트, 높은 채도,
  20대 타깃의 발랄한 톤. `docs/03-design-system.md`가 명시적으로 피하라고 한
  "youthful K-beauty gloss"가 바로 이것. **우리 반례로 문서에 박아둔다.**

### 후보 C — @todayhouse (오늘의집) · 팔로워 130만
**담당 차원: ⑤ 커머스 전환**

  "판매"가 아니라 "발견"으로 프레이밍하는 화법.
- **버릴 것**: 인테리어 도메인 특유의 유저 생성 콘텐츠(집들이) 의존.
  우리는 UGC가 아직 없으므로 에디토리얼로 가야 한다.

### 후보 D — @aesop · 팔로워 130만
**담당 차원: ② 시각 언어**

- 뷰티에서 **얼굴 없이, 정물과 타이포만으로** 성분·처방을 이야기하는 정점.

  "읽고 뭘 사야 할지 알 수 있어야" 한다.

## 4. 아직 결정 안 된 것 (만들기 전에 정해야 함)

1. **카테고리 라벨 체계**: glowupmag의 Item/Place/Others처럼 우리도 코너를 만들 것인가?
   (예: `성분` / `제품` / `루틴` / `생활`) — 만들면 시리즈가 되고, 안 만들면 매번 단발이 된다.
2. **워터마크**: 매 장에 `RIVEA MAG`를 넣을지, 지금처럼 앞뒤 표지만 할지.
   glowupmag은 매 장에 넣는다(도난 방지 + 인지). 현재 우리는 표지만.
3. **제품 추천 회차의 사진**: 실제 제품 사진이 없다. 무료 스톡의 무지 제품 정물로
   상징적으로 갈지, 카테고리별 무드 컷으로 갈지.
4. **인용/대화체 도입 여부**: glowupmag의 `"큰따옴표 한 문장"`을 우리도 쓸지.
   현재 우리 헤드라인은 선언형("건조는 결과가 아니라 원인이다").
