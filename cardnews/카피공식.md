# PART 1. 캐러셀 구조 공식 10가지

## 1️⃣ H–I–R–A · Hook → Interest Loop → Reveal → Action

2026 인스타 알고리즘에 가장 잘 맞는 구조. 체류시간·저장·공유를 한 번에 잡는 메인 공식.
**쓸 때**: 마케팅 / 브랜딩 / 교육 / 정보형 · **목적**: 체류시간 극대화 + 저장·공유 유도

```
[1~2장 | Hook]
 → 많은 분들이 [당연하다고 믿는 것]을 그대로 하고 있어요
 → 근데 그렇게 하면 [예상치 못한 문제]가 생깁니다

[3~6장 | Interest Loop]
 → 왜 [문제]가 계속 반복될까요?
 → 정말 [표면적인 이유] 때문일까요?
 → 사실 대부분 같은 지점에서 막혀요

[7~9장 | Reveal]
 → 원인은 [기존에 생각하던 것]이 아니에요
 → 진짜 핵심은 [새로운 관점]에 있었습니다

[10장 | Action]
 → 이 구조, 바로 다음 콘텐츠에 써보세요 👉 저장해두세요
```

**예시**
- Hook: "캐러셀 꾸준히 올려도 절대 안 터지는 이유가 있어요"
- Interest Loop: "정보는 충분한데 왜 반응이 없을까요? 알고리즘 탓이라고 생각하시죠? 사실 대부분 같은 실수를 하고 있어요"
- Reveal: "문제는 정보량이 아니라 '넘기고 싶은 흐름'이 없다는 거예요"
- Action: "이 구조로 만들어보세요 👉 저장 필수"

## 2️⃣ P–A–F · Problem → Agitation → Fix

손해 회피 심리를 자극. 댓글·공유가 강하게 터짐.
**쓸 때**: 다이어트 / 헬스 / 자기계발 · **목적**: 문제 인식 강화 + 행동 변화

```
[1~3장 | Problem]    → [이렇게 노력]하는데 왜 [원하는 결과]가 안 나올까요?
[4~6장 | Agitation]  → 이 방식 계속 가면 [구체적인 손해]가 생겨요 / 실제로 대부분 여기서 포기합니다
[7~9장 | Fix]        → 문제는 [잘못된 접근 방식]이었어요 / [새로운 기준]부터 바꿔야 합니다
```

**예시**: "매일 운동하는데 왜 몸은 그대로일까요?" → "이 패턴 계속 가면 체력만 떨어지고 결국 포기하게 돼요. 다이어트 실패자 90%가 여기서 멈춰요" → "문제는 운동이 아니라 단백질 섭취 타이밍이었습니다"

## 3️⃣ M–R–C · Myth → Reality → Conclusion

상식을 깨는 반전 구조. **저장률이 유독 높음.**
**쓸 때**: 금융 / 투자 / 헬스 정보 / 마케팅 인사이트 · **목적**: 인식 전환 + 전문가 포지셔닝

```
[1~3장 | Myth]       → 대부분 이렇게 알고 계실 거예요 / [널리 퍼진 잘못된 믿음]
[4~7장 | Reality]    → 근데 실제 데이터는 달라요 / [수치 또는 사례]
[8~9장 | Conclusion] → 이제 이 기준으로 생각하셔야 해요 / [새로운 프레임]
```

**예시**: "릴스만 해야 성장한다?" → "캐러셀 체류시간이 릴스보다 높았고, 저장·공유는 캐러셀이 압도적" → "2026년 인스타 성장 전략의 핵심은 캐러셀입니다"

## 4️⃣ B–A–D · Before → After → Difference

변화 전후가 명확한 성과형. **팔로우 전환에 강함.**
**쓸 때**: 마케팅 성과 / 다이어트 / 성과 기반 · **목적**: 신뢰 확보 + 팔로우 전환

```
[Before]     → 예전엔 [반복되던 문제 상황]이 계속됐어요
[After]      → 지금은 [눈에 보이는 결과]가 나오고 있어요
[Difference] → 바뀐 건 딱 하나, [결정적인 변화]였습니다
```

**예시**: "하루 1피드 꾸준히 올려도 반응은 항상 0에 가까웠어요" → "썸네일 구조 하나 바꿨을 뿐인데 조회수 100만" → "콘텐츠 퀄리티가 아니라 '첫 장 설계'가 문제였어요"

## 5️⃣ Q–Q–A · Question → Question → Answer

질문으로 스와이프를 끌어냄. 체류시간이 길게 나옴.
**쓸 때**: 교육 / 지식 계정 / 마케팅·전략 · **목적**: 궁금증 유발 + 넘김 유도

```
[Question] → 왜 [이런 현상]이 생기는 걸까요? / 정말 [표면적인 이유] 때문일까요?
[Answer]   → 이유는 단 하나예요 / [핵심 원인]
```

**예시**: "좋아요는 쏟아지는데 왜 팔로우는 안 할까요? 콘텐츠가 부족해서일까요?" → "이유는 하나예요. 계정 컨셉이 한 문장으로 안 보이기 때문입니다"

## 6️⃣ S–C–S · Situation → Conflict → Solution

스토리텔링 기반. 감정 이입이 자연스럽게 일어남.
**쓸 때**: 퍼스널 브랜딩 / 스타트업 / 창업 · **목적**: 신뢰 형성 + 브랜드 서사

```
[Situation] → 처음엔 [무작정 시도한 것]을 했어요
[Conflict]  → 근데 [문제 상황]이 계속 반복됐어요
[Solution]  → 알고 보니 [의외의 원인]이 문제였습니다
```

## 7️⃣ L–E–S · List → Explanation → Summary

**저장률이 가장 높게 나오는 실용 공식.**
**쓸 때**: 헬스 / 식단 / 업무·툴 정리 · **목적**: 정보 정리 + 체크리스트

```
[List]        → 잘 되는 [주제] 5가지
[Explanation] → 첫 번째: [핵심 포인트] / 두 번째: [핵심 포인트] …
[Summary]     → 이 5가지만 지켜도 결과가 달라져요
```

## 8️⃣ F–R–F · Fact → Reason → Framework

실제 성과로 신뢰를 만드는 전문가 공식.
**쓸 때**: 컨설팅 / 마케팅 전략 / 데이터 기반 · **목적**: 전문성 증명

```
[Fact]      → [구체적인 수치 성과]를 만들었어요
[Reason]    → 이유는 [구조적인 원인]이었습니다
[Framework] → 그래서 저는 이 3단계를 씁니다
```

## 9️⃣ E–M–E · Experience → Meaning → Expansion

팔로워를 팬으로 만드는 공식.
**쓸 때**: 퍼스널 브랜딩 / 코치 / 강사 · **목적**: 공감 형성 + 팬화

```
[Experience] → 저도 [정체·실패 경험]을 겪었어요
[Meaning]    → 그때 깨달은 건 [의외의 인사이트]였어요
[Expansion]  → 이 이야기가 당신에게 중요한 이유는 …
```

## 🔟 T–W–H · This → Why → How

짧고 강하게 핵심을 전달.
**쓸 때**: 정보 요약형 / 신규 계정 / 빠른 메시지 · **목적**: 신규 유입 + 빠른 이해

```
[This] → [핵심 주장] 한 문장
[Why]  → 왜냐하면 [이유] 때문이에요
[How]  → 그래서 이렇게 하시면 됩니다
```

# PART 2. 카피라이팅 원리 (원문 요지)

## 썸네일이 95%다

카드뉴스는 첫 장에서 판가름 난다. 디자인이 아니라 **카피라이팅**이 승부처다.
기획부터 업로드까지 30분 안에 끝낼 수 있다. **마케팅에 오랜 시간을 투자하지 말고
본질을 채우는 데 투자하라.**

### 카피 3원칙

1. **최대한 줄인다**
2. **직관적으로 적는다**
3. 1·2번을 잊지 않는다

**줄이기 예시**
```
❌ 2026년 군대를 가는 후임들에게 25살 선임이 전하고 싶은 말
✅ 2026년 군대 가는 후임에게 25살 선임이 전하는 말
```
- 군대를 가는 → 군대 가는
- 후임들에게 → 후임에게
- 전하고 싶은 말 → 전하는 말

**이유**: 인스타는 가볍게 소비하는 콘텐츠다. **1~2초 안에 읽히고 해석에 무리가 없어야 한다.**
글 읽는 데 에너지가 쓰이면 피로를 느끼고 넘긴다. 독자의 에너지를 아껴줘라.

### 구체적으로 써라 — "맛을 살린다"

```
❌ 열심히 운동하라        ✅ 주 7일 운동하라
❌ 스토킹은 범죄입니다     ✅ 스토킹 범죄는 최소 1년의 징역입니다
```

사람들은 뜬구름 잡는 걸 싫어한다. **정확히 뭘 하라는 건지 알려줘야 후킹이 되고 호기심이 발동한다.**

### 숫자를 넣어라

```
❌ 큰 돈을 버는 방법                  ✅ 월 1억 버는 방법
❌ 값싸면서 좋은 지갑을 사는 방법        ✅ 2만원 이하 가성비 최고 지갑 구하는 방법
❌ 청년이 노가다 오래 뛰면서 큰 돈을 벌고 그만 둔 날
✅ 24살 노가다 7개월 3000만원 벌고 그만 둔 날   ← 숫자 3개
```

**숫자는 뇌를 거치지 않아도 바로 파악된다.** 직관성의 최고 도구다.

## 본문 3요소

### ① 권위부여

> "거짓말이 아니라, 행군이 끝나고도 스쿼트를 했다"

좋은 말은 챗GPT도 할 수 있고 초등학생도 따라 할 수 있다. **그런 글엔 가치가 없다.**
"주 7일 운동하라"는 누구나 말할 수 있지만, **"나는 행군하고 스쿼트하던 놈이고, 주 7일 운동하니
인생이 바뀌더라"**가 되는 순간 독자의 무의식이 집중한다.

**권위부여가 없으면 모든 글은 의미가 없다.** "아, 이 사람 진짜다"는 감정은 내 관점과
내 경험에서만 나온다.

### ② 스토리 · 나의 관점

퍼스널 브랜딩은 **무수한 경쟁자 중 굳이 나를 선택해야 하는 이유를 만드는 것**이다.
퍼다 나른 정보성 콘텐츠는 조회수는 뽑아도 선택받는 이유가 되지 못한다.

### ③ 정확한 행동 지침서

> "헬창 선임이든 후임이든 몸 좋으면 친해져라"

**사람들은 게으르고, 읽고 나서 뭘 해야 할지 모른다.** 바로 행동할 수 있는, 기억할 수 있는
한 문장을 마지막에 넣어야 한다.

이 한 줄이 들어가느냐로 **저장수와 공유수가 갈린다.** 독자가 그 순간 판단하기 때문이다:
> "아 나도 그렇게 해야지" / "친구한테 공유해줘야지" / "나중에 다시 꺼내봐야지"

**카드뉴스는 저장률과 공유수에서 바이럴이 갈린다.**

## 캡션 첫 줄 = 2차 후킹

- **1차 카피** = 이미지 상단의 큰 글
- **2차 카피** = 캡션의 첫 줄

캡션을 열기 전에 보이는 건 첫 줄뿐이다. 여기서 **상상하게 만들어야** 캡션을 연다.

```
❌ 나는 24살 평범한 남자인데..
✅ 그저 감사할 뿐이다
```

## 똑똑한 벤치마킹

창작하려 들면 시간이 엄청나게 들고 초반엔 되지도 않는다.
**이미 검증된 포맷의 키워드만 바꿔라.**

```
원본:  2026년 군대 가는 후임에게 25살 선임이 전하는 말
학생:  2026년 대학 가는 후배에게 25살 선배가 전하는 말
헬스:  1년 차 헬린이에게 10년차 헬창이 전하는 말
```

**기준**: 최소 30만 조회수, 공유 2,000개 이상을 확인하고 벤치마킹한다.
벤치마킹은 부끄러운 게 아니다. **다만 본문 글까지 똑같아지면 그건 모방이다.**

### 해외 포맷 선점

국내 콘텐츠의 상당수가 해외에서 먼저 유행한 뒤 들어온다. 국내에서 이미 터진 걸
따라 하면 같은 영상이 넘쳐서 주목을 못 받는다. **해외에서 퍼지는 포맷을 먼저 캐치해서
키워드만 바꿔 올리는 게 효과적이다.**
방법: 인스타 검색에 `#work` `#viral` 등 영어 키워드로 현재 바이럴 영상을 찾는다.

## 스토리텔링 프레임워크 (『무기가 되는 스토리』)

```
후킹 (3초)  →  캐릭터(원하는 고객)  →  문제(난관)  →  가이드와의 만남  →  성공 or 실패
```

**후킹 포맷 예**: "지금부터 저는 ~ 해보겠습니다"

**적용 예 (트레이너)**
```
후킹    저는 지금부터 100kg 회원님을 70kg으로 빼보겠습니다
주인공  옛날에 뚱뚱한 게 부끄러워 다이어트를 성공하고 트레이너가 됐는데요
연결    옛날의 저와 같이 살 때문에 우울한 회원님이 저를 찾아왔습니다
난관    회원님의 문제는 매일 콜라를 마신다는 거였죠
가이드  쉽지 않았습니다. 제가 지도한 이 방법으로 3개월 진행했고
성공    결국 목표보다 높은 60kg을 만드는 데 성공했습니다
```

**핵심**: 문제가 발생하고 그걸 해결하는 과정을 볼 때 사람들이 기대를 갖고 본다.
히어로가 계속 강하기만 하면 아무도 안 본다.

## 신뢰 프레임워크 (6단계)

```
1. 후킹
2. 공감 키워드 및 문제제기
3. 그 한계점 제시
4. 나의 의견 제시
5. 근거 제시
6. 다시 주장
```

**포인트**: 사람들이 가진 문제를 인지시키고 그 한계를 알려준 다음 내 의견을 제시하면,
귀 기울이고 경청하게 된다.

## 콘텐츠 소재는 DM과 댓글에 있다

터지는 키워드를 찾아다니고 트렌드를 쫓을 필요가 없다.
**좋은 콘텐츠를 올리고 있으면 사람들이 무슨 콘텐츠를 올려야 할지 알려준다.**
DM과 댓글에서 "사람들이 나에게 원하는 게 무엇인가"를 파악하는 것 —
**이것이 인스타그램 데이터 분석의 끝이다.**

## 조회수는 본질이 아니다

- 100만 조회수로는 팔로우 전환이 많이 일어나지 않는다
- **찐팬은 "아, 이 사람 진짜구나" 싶을 때 생긴다**
- 본질이 담긴 20만 조회수가 허상 100만보다 낫다
- 하루 30분 이상 제작에 투자하지 말고, **본질을 배우는 데 시간을 쓴다**
- WHY가 명확한 사람에게 DM과 댓글이 쏟아진다

# PART 3. RIVEA에 어떻게 적용하나

> 아래는 위 자료를 RIVEA 상황에 붙인 우리 메모다. 원문이 아니다.

## 우리에게 맞는 공식은 3개다

| 공식 | 왜 우리에게 맞나 | 소재 |
|---|---|---|
| **M–R–C** (Myth→Reality→Conclusion) | **`rules.ts` 병용 규칙이 전부 이 형태다.** "이렇게 알고 계실 텐데 사실은 반대예요" | 레티놀×AHA · 비타민C 아침/레티놀 저녁 · **LED는 바르기 전, 갈바닉은 바른 후** |
| **P–A–F** (Problem→Agitation→Fix) | 겹치게 쓰면 실제로 손해(돈·피부)를 본다. 손해 회피가 정확히 작동 | 나이아신아마이드 중복 함량 · 레티놀 쓰면서 자외선 차단 누락 |
| **L–E–S** (List→Explanation→Summary) | 저장률 최고 공식. 1회차 「백세시대」가 이미 이 형태였다 | 성분 5가지 · 기기 5종 비교 |

**M–R–C가 우리 1순위다.** 「같이 쓰면 안 되는 조합」은 검색량이 **월 0회**인데
(`docs/10-keyword-findings.md` §1), 그건 **아무도 모른다는 뜻**이고
**Myth를 깨는 구조에는 최적**이다. 검색으로는 못 파는 정보를 피드로는 팔 수 있다.

## 우리의 「권위부여」는 무엇인가

원문의 핵심은 **"좋은 말은 챗GPT도 한다. 내 경험에서 나온 말이어야 한다"**다.
RIVEA는 개인 스토리가 약한 대신 다른 권위가 있다:

- **식약처 고시 함량** (1회차에서 이미 쓴 방식. 유지)
- **국표원 안전확인 인증 여부** — 인증받은 LED 마스크가 시중 수십 종 중 4개뿐이다
- **2019년 식약처가 LED 마스크 48품목에 시정명령을 낸 사유**
- **`rules.ts` 13개 규칙** — 어느 설명서에도 나란히 안 적혀 있는 조합

⚠️ 개인 경험담을 지어내지 않는다. **없는 권위를 만드는 것보다 있는 근거를 쓰는 게 낫다.**

## 마지막 장 = 행동 지침서 + CTA

원문: *"이 한 줄이 들어가느냐로 저장수와 공유수가 갈린다."*

우리 CTA는 이것이다 (`docs/09` §그로스 참고):

> **"지금 쓰시는 거 3개만 DM으로 보내주세요. 겹치는 게 있는지 봐드릴게요."**

- 저장·공유를 만드는 「행동 지침서」이면서
- **동시에 수요 증거를 만드는 리드 수집이다**
- 그리고 원문이 말한 *"DM과 댓글이 콘텐츠 소재의 원천"*이 그대로 작동한다

**프로필 링크: `rivea-app.web.app`** — 지금 어디에도 안 걸려 있다. 이게 최우선.

## 우리가 지켜야 하는 선 (원문과 충돌하는 부분)

| 원문 | RIVEA 제약 |
|---|---|
| "숫자를 넣어라" | ⭕ 함량·파장·무게는 OK. ❌ **효과 수치는 금지** (화장품법 13조 실증 대상) |
| "구체적으로, 맛을 살려라" | ⭕ "나이아신아마이드 2~5%" OK. ❌ **"기미 없애는 법"은 의약품 오인** |
| "검증된 포맷 벤치마킹" | ⭕ 구조는 벤치마킹. ❌ **브랜드 비방·비교는 별표5-2 카 위반** |
| "자극적인 후킹" | ⭕ 반전·호기심 OK. ❌ **"최고·최상" 근거 없는 표현은 별표5-2 바 위반** |

`docs/07` §10의 카피 예시가 기준이다:
```
❌ 40대 여성들에게 좋은 세럼 5가지    → 별표5-2 바·카
✅ 나이아신아마이드, 40대엔 왜 5%를 고르나
❌ 노화 늦추는 법 5가지               → 제14조 실증 대상
✅ 45세 전후, 관리 순서가 바뀌는 이유
```

## 3회차 초안 (M–R–C 적용)

```
[1~3장 Myth]
  세럼 두 개 겹쳐 바르면 더 좋은 거 아니에요?
  비싼 거 여러 개 쓰면 효과가 쌓일 것 같죠

[4~7장 Reality]
  레티놀과 AHA/BHA는 같은 날 저녁에 겹치면 자극이 커집니다
  비타민C는 아침, 레티놀은 저녁 — 나눠 쓰는 이유가 있어요
  나이아신아마이드는 제품 두 개에 다 들어 있으면 함량이 합산됩니다
  레티놀을 쓰면 아침 자외선 차단이 선택이 아니라 필수가 돼요

[8~9장 Conclusion]
  더 많이 바르는 게 아니라 언제 무엇과 쓰는지가 순서를 정합니다

[10장 Action]
  지금 쓰시는 거 3개만 DM으로 보내주세요. 겹치는 게 있는지 봐드릴게요
  👉 저장해두고 화장대 앞에서 보세요
```

⚠️ 각 문장의 근거는 `src/lib/rules.ts`에 있는 규칙 그대로 쓴다. **새로 지어내지 않는다.**
⚠️ 함량·수치는 `운영.md` 원칙대로 **2회 이상 교차 확인.** 확인 못 하면 안 쓴다.
