# 카드뉴스 스타일 가이드 (인스타 매거진)

> 근거: `docs/03-design-system.md`(웜 뉴트럴 모노크롬 · 각진 · 풀블리드)에서 파생.
> 이 파일이 **디자인의 단일 기준**이다. 회차마다 다시 정하지 말고 이 문서를 따른다.
> 방법론 근거: `docs/08-cardnews-research.md` 핵심요약 2번(디자인을 문서로 고정해야 퀄이 일정해진다).

## 0. 절대 규칙

- **브랜딩은 앞뒤 표지에만.** (2026-08-03 변경 — 이전 "브랜드 언급 금지" 규칙 폐기)
  - **매 장 공통 프레임** (2026-08-05 변경): 좌상단 `▪ 코너명` + 우상단 `RIVEA MAG`.
    코너명은 재사용한다 — `제품` / `성분` / `루틴` / `생활`. 이게 시리즈감을 만든다.
  - 마지막 카드: 브랜드 아웃트로 1장
  - 구매 링크는 넣지 않는다. 저장·팔로우까지만.
- **판형**: 1080 × 1350 (4:5). 인스타 캐러셀 표준.
- **생성 방식**: 순수 HTML/CSS → Playwright 스크린샷 → PNG. 이미지 생성 AI로 카드를 만들지 않는다.
- **AI 슬롭 금지**: 보라/바이올렛 그라데이션, 흰 배경 둥근 카드 남발, 골드 액센트, serif 장식체, 네온, 글래스모피즘.

## 1. 컬러

| 역할 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FFFFFF` | (v2에선 카드 배경 = 사진. 흰 배경 카드 없음) |
| `--ink` | `#1C1815` | 제목·강조 |
| `--body` | `#4A443E` | 본문 |
| `--muted` | `#8B8279` | 캡션·라벨·페이지번호 |
| `--line` | `#E5DFD6` | 헤어라인 |
| `--line-strong` | `#D0C8BD` | 강조 구분선 |
| `--accent` | `#C13B54` | **유일한 유채색.** 원칙 번호와 성분 라벨에만. |

- 액센트는 카드당 **2곳 이하**. 남발하면 무채색 기조가 무너진다.
- 사진 위 텍스트 대비는 **아이보리 베일**로 확보한다(4항 참고). 어두운 스크림 + 흰 텍스트는 쓰지 않는다.

## 2. 타이포그래피

**Pretendard** 단일 패밀리. 위계는 크기·굵기·색으로만. 굵기는 400/500/700만.

| 역할 | 크기 / 굵기 | 자간 | 행간 |
|---|---|---|---|
| 커버 헤드라인 | 98 / 700 | -0.04em | 1.18 |
| 커버 한 줄 | 31 / 500 | -0.01em | 1.4 |
| 라벨 (01 자외선) | 25 / 700 | 0.20em | 1 |
| 카드 헤드라인 | 80 / 700 | -0.035em | 1.22 |
| 정보 1줄 (성분명) | 33 / 500 | -0.01em | 1.45 |
| 정리 카드 리스트 | 37 / 700 | -0.02em | 1 |
| 페이지번호 | 23 / 600 | 0.16em | 1 |

- 헤드라인은 **2줄**로 끊는다. 3줄이 되면 문장을 줄인다.
- 줄바꿈은 의미 단위로 직접 넣는다(`<br>`). 자동 줄바꿈에 맡기면 어색해진다.

## 3. 형태·여백

- **라운드 4px**만 (페이지번호 받침 등). 둥근 사각형·pill 금지.
- **사진은 카드 전체 풀블리드.** 프레임·테두리·여백 없음.
- 텍스트 블록 좌우 여백 **80px**, 상단(또는 하단) **88px**.
- 구분선은 `1px solid rgba(28,24,21,.16)` 헤어라인만.
- 그림자 없음.

## 4. 카드 포맷 — **v2(사진 배경형)를 표준으로 쓴다**

레퍼런스: **`references.md` 참고.** 차원별로 담당 레퍼런스가 다르다
(포맷 @glowupmag / 시각언어 @aesop / 콘텐츠뼈대 @hwahae_official / 커머스 @todayhouse / 반례 @oliveyoung_magazine).

**모든 카드가 풀블리드 사진 배경이다.** 흰 본문 카드를 만들지 않는다.
카드 1장에 들어가는 텍스트는 **최대 3덩어리**:

```
라벨 (예: 01 자외선)        — 25px
헤드라인 2줄                 — 76px   ← 크게
본문 2~3문장 (2~3줄)         — 33px   ← 작게. 실제로 내용을 말한다
성분 1줄                     — 30px
```

- **큰 제목 ↔ 작은 본문의 대비가 이 포맷의 핵심.** 본문을 키워서 대비를 죽이지 말 것.
- 본문은 "아 이게 이런 내용이구나"까지만. **실천법·농도·주의사항은 카드에 넣지 않고 캡션으로.**
  카드가 사용설명서가 되면 스와이프가 멈춘다.
- 역할 분담: **카드 = 무엇을 알아야 하나 / 캡션 = 어떻게·왜·주의.**
  캡션이 카드 문장을 반복하면 안 된다. 캡션을 읽어야 실행이 가능해져야 한다.
- 총 **8장** 기본: 커버 1 + 원칙 5 + 정리 1 + **브랜드 아웃트로 1**.
- 정리 카드만 예외로 짧은 5줄 리스트(키워드만) 허용.

### 브랜드 아웃트로 카드 (마지막 1장, 유일하게 사진 없음)
사진 7장 뒤에 오는 **웜화이트 타이포 카드**. 캐러셀이 끝났다는 신호가 되므로 사진을 쓰지 않는다.
```
배경        #FAF7F2 + 상단 아주 옅은 화이트 방사 그라데이션 (평평해 보이지 않게만)
한글 한 줄  38px / 500 / --body      예) 당신이 푸르렀던 그 시절로
캐치프레이즈 144px / 700 / --ink     예) RE:BEAUTY  ← 콜론만 --accent
가운데 룰   92 × 1px, rgba(28,24,21,.26)
워드마크    46px / 700 / letter-spacing .44em / --accent(rivea-rose)
```
- 블록은 **정중앙이 아니라 top:45%** (광학 중심 — 아래 여백이 더 넓어야 안정적으로 보인다).
- 페이지번호를 넣지 않는다. 커버(`ISSUE 01`)와 아웃트로가 앞뒤 표지로 짝을 이룬다.

### 텍스트 대비 — 잉크 텍스트 + 아이보리 베일
밝은 웜톤 사진을 쓰므로 **흰 텍스트가 아니라 잉크(`--ink`) 텍스트**를 올린다.
(어두운 사진 + 흰 텍스트는 흔하고, 우리 웜 뉴트럴 기조와도 안 맞는다.)

가독성은 **아이보리 베일**로만 확보한다. 사진 분위기를 죽이지 않는 게 핵심:
```
기본  rgba(250,247,242, .68 → .46 → 0)   높이 58%
.deep rgba(250,247,242, .90 → .70 → 0)   어두운 사진에만
.thin rgba(250,247,242, .62 → 0)         높이 16%, 페이지번호 가독성용
```
> 초기에 .93/.86으로 깔았더니 사진이 크림색으로 뭉개졌다. **베일은 최소한만.**

- 텍스트는 사진의 **빈 영역 쪽에 앵커**한다(`.txt.top` / `.txt.bot`).
  피사체가 위쪽인 사진은 텍스트를 아래로. 위치 통일보다 사진과의 관계가 우선.
- 페이지번호는 옅은 아이보리 받침(4px)을 깔아야 질감 있는 배경에서도 읽힌다.

## 5. 사진 규칙

- 출처는 **Unsplash / Pexels만** (상업적 사용 허용, 출처표기 불필요). 큐레이션 사이트(핀터레스트·cosmos 등)는 원본 권리가 불명확하므로 사용 금지.
- **인물보다 분위기.** 정물·제품·텍스처·빛/그림자로 무드를 만든다. 얼굴은 넣어도 되지만 전부 사람 사진으로 채우지 않는다.
  → 부수 효과: 얼굴이 없으면 초상권·상품보증 제약이 사라져 재사용이 자유롭다.
- 인물을 쓸 경우: 45~65세 여성, 자연스러운 피부 질감. 과도한 리터칭·화려한 메이크업·K뷰티 광채 금지.
- **텍스트 앉힐 빈 영역이 있는 컷을 고른다.** 꽉 찬 사진은 아무리 예뻐도 못 쓴다.
- 밝은 웜톤(아이보리/베이지)으로 통일하면 7장이 저절로 한 세트가 된다.
- **다른 브랜드 제품의 로고·라벨이 읽히면 안 된다.** 읽히면 크롭으로 제외.
- **통일 그레이딩 필수** (이게 브랜드 느낌을 만든다):
  ```
  채도 0.58 · R×1.05+3 · B×0.93 · 대비 1.06 · 밝기 1.02
  ```
  출처가 달라도 이 그레이딩을 거치면 한 세트로 읽힌다.

## 5-B. 제품 추천 회차 전용 규칙 (2026-08-05 신설)

실제 브랜드 제품을 추천하는 회차는 아래를 전부 지킨다.

- **브랜드 로고 이미지를 쓰지 않는다.** 로고는 저작권물이면서 상표라 붙이면 협찬 오인 소지가 생긴다.
  1080px 카드에서는 로고보다 **제품명을 Pretendard로 크게 쓰는 게 더 잘 읽힌다.** 목적은 텍스트로 달성된다.
  (업계 관행은 프레스킷을 받아 `📷브랜드`로 출처 표기하는 것. 제휴 후에 실제 제품컷으로 교체한다.)
- **가격을 카드에 넣지 않는다.** 세일가는 수시로 바뀐다. 캡션도 "○만 원대"까지만.
- **협찬을 받았으면 반드시 공개한다** (경제적 이해관계 표시). 표시광고법이 요구하는 건 이쪽이다.
  반대로 **협찬이 없을 때 「협찬 아님」을 쓰는 건 의무가 아니다.** 신뢰 장치일 뿐이니
  톤에 맞지 않으면 빼도 된다. (2026-08-18 정정 — 이전 서술은 의무처럼 읽혀 부정확했다)
- **제품명에 이미 박혀 있는 성분만 카드에 쓴다.** 전성분표를 직접 확인하지 않았으면
  그 이상 단정하지 않는다. (예: `레티놀 0.1`, `우레아 12%`는 제품명에 있어 안전)
- **식약처 기능성 고시 문구는 등록 확인 없이 쓰지 않는다.**
  `주름개선`·`미백`은 고시 문구 → 확인 못 했으면 `주름 관리`처럼 일반 표현으로.
  단, 상품명에 이미 `탈모증상완화` 등이 박혀 있으면 그대로 쓸 수 있다.
- **자극 가능성이 있는 성분은 사용법을 캡션에 반드시 넣는다.** (레티놀: 밤에만·주 2~3회부터·자차 필수)
- 근거는 `products.md`에 **검증한 것 / 검증 못 한 것**을 나눠서 남긴다.
- 게시 직전 **재고·가격 재확인**.

## 6. 콘텐츠 규칙

- 커버 1 + 원칙 5 + 정리 1 + 브랜드 아웃트로 1 = **8장** 기본.
- 카드에는 **헤드라인 + 2~3문장 + 성분 1줄**. 실천법·농도·주의사항은 캡션.
- 각 카드에 성분 한 줄은 반드시 있어야 한다. 감상만 있으면 저장되지 않는다.
- 본문이 4줄을 넘으면 문장을 줄인다. 베일 유효구간(상단 베일의 80%)을 벗어나면 가독성이 깨진다.
  → `node veilcheck.mjs <에피소드>`로 검사. 내용이 많은 정리 카드만 `.veil.full`(전체 높이·저농도) 사용.
- 수치는 통용되는 범위만 쓰고 단정하지 않는다("~로 알려져 있다").
- **면책 문구는 캡션에 필수** (카드에는 넣지 않는다 — 카드는 최소한만): 일반 정보임 / 개인차 있음 / 질환·복용약 있으면 전문가 상담.
- 판매 유도·구매 링크 금지. 저장·팔로우 유도까지만. (브랜딩은 표지에서만 한다)

## 7. 브랜드 마무리 카드 (2026-08-15 고정)

**마지막 장은 매 회차 동일하다. 회차마다 다시 만들지 않는다.**
마지막 장이 매번 같아야 시리즈로 읽히고, 스와이프를 끝까지 한 사람이
"아, 그 계정"으로 기억한다. 여기를 회차마다 바꾸면 그 자산이 쌓이지 않는다.

```html
<section class="card outro" id="c8">
  <div class="outro-in">
    <p class="pre">당신이 푸르렀던 그 시절로</p>
    <p class="rebeauty">RE<span>:</span>BEAUTY</p>
    <div class="rule-c"></div>
    <div class="fcard">                          <!-- 2026-08-09 추가 -->
      <img class="av" src="../../assets/avatar.png" alt="">
      <div class="who">
        <div class="nm">RIVEA 매거진</div>
        <div class="hd">@rivea.mag</div>
      </div>
      <div class="btn">팔로우</div>
    </div>
  </div>
</section>
```

### 팔로우 카드는 왜 마지막 장인가 (2026-08-09 결정)

처음엔 **정리 카드(7번)에 팔로우 문구**를 넣었다. 틀렸다.
그 구조는 **7번에서 행동을 요청하고 8번에서 로고를 보여준다.** 스와이프를 끝낸 시점이
행동 시점인데, 그때 화면에 남는 건 요청이 아니라 로고다. **요청이 마지막에 있어야 한다.**

- 인스타 프로필 카드 UI를 빌리되 **버튼은 pill이 아니라 4px 라운드**로 (3항 유지).
- 아바타는 `cardnews/assets/avatar.png` — **실제 프로필 사진과 같은 이미지**를 쓴다.
  다른 이미지를 쓰면 눌러야 할 대상이 헷갈린다.
- 워드마크(`.wordmark`)는 **팔로우 카드가 대체한다.** 핸들이 이미 브랜드명이라 중복이다.
- 팔로우 카드가 붙어 블록이 길어졌으므로 **`top:45%` → `top:50%`**.
  광학 보정은 블록이 짧았을 때 맞던 값이다.
- 7번 정리 카드는 **저장 유도까지만** 한다. 두 장에서 각각 다른 행동을 요청한다
  (7번=저장 / 8번=팔로우). 같은 요청을 두 번 하지 않는다.

| 요소 | 값 |
|---|---|
| 배경 | `#FAF7F2` + 상단 radial 화이트 오버레이(평평해 보이지 않게만) |
| 세로 위치 | `top:45%` — 정중앙보다 살짝 위. 아래 여백이 넓어야 시각적으로 안정된다(광학 중심) |
| 리드 문장 | 38 / 500 · `--body` · **「당신이 푸르렀던 그 시절로」** |
| 로고타입 | 144 / 700 · 자간 .005em · `--ink`, 콜론(`:`)만 `--accent` |
| 구분선 | 92 × 1px · `rgba(28,24,21,.26)` · 위 여백 52 |
| 워드마크 | 46 / 700 · 자간 .44em · `--accent` (`text-indent`로 자간 보정) |

- **사진을 넣지 않는다.** 8장 중 유일한 무사진 카드이고, 그래서 끝이라는 게 읽힌다.
- 액센트가 콜론 + 워드마크 두 곳이다. 「카드당 2곳 이하」(1항)를 지키는 구성이다.
- 이 카드는 `veilcheck`·`measure` 검사 대상이 아니다(사진·`.txt` 없음). 두 스크립트 모두
  못 찾으면 건너뛰도록 되어 있다.
- **고칠 일이 생기면 이 문서를 먼저 고치고 전 회차에 같이 반영한다.** 한 회차만 바꾸지 않는다.

## 8. 리서치 포맷 (2026-08-21 신설)

정보형 회차의 **기본 포맷**이다. 뷰티 무드는 그대로 두고 **근거를 전면에 세운다.**
주장의 출처가 우리뿐이면 「그렇대요」에서 멈춘다. 이 포맷은 9장 중 **두 장을 근거에만 쓴다.**

```
01 문제 제기      독자가 겪는 상황 한 문장
02 공감           우리 설문·데이터로 「나만 그런 게 아니다」
03 손해           그대로 두면 뭘 잃는지
04 근거 · 인용    ← 인용 카드
05 근거 · 수치    ← 수치 카드
06 해석           그래서 이게 무슨 뜻인지
07 행동           그러니 이렇게
08 정리 + CTA     5줄 + 저장 → 팔로우
09 아웃트로       고정 (§7)
```

### 절대 규칙 — 논문 이미지를 가져오지 않는다

- **논문 지면·PDF 캡처 금지.** 저널 레이아웃은 저작물이고, 1080px에서 본문이 읽히지도 않는다.
- **연구자 사진 금지.** 초상권이다. 언론 배포 사진이라도 맥락이 바뀌면 문제가 된다.
- **저널 로고 금지.** 상표다. 5-B와 같은 판단 — **저널명을 Pretendard로 적는 게 더 잘 읽힌다.**
- **기관 후광 금지.** 「하버드 연구에 따르면」식으로 실제 소속이 아닌 이름을 빌리지 않는다.

→ 대신 **인용을 타이포로 재조판한다.** 출처가 카드 안에 박혀 있는 게 캡처보다 신뢰가 높다.

### 논문 지면 배경 — 두 가지 방법 (2026-08-21 추가)

근거 카드(04·05)는 **사진 대신 논문 지면을 배경으로 깐다.** 위에 큰 카피를 얹으면
「근거 위에 말한다」가 시각적으로 성립한다.

**절대 조건: 실제 논문 지면을 쓰지 않는다.** 흐리게 깔아도 복제다. 두 가지 대안이 있다.

| 방법 | 언제 | 주의 |
|---|---|---|
| **① 지면 사진** (채택) | 지면처럼 보이는 이미지가 있을 때 | **글자가 실제 문장이면 안 된다.** 읽히는 순간 어떤 문헌인지 문제가 된다 |
| **② CSS로 그린 지면** (`.paperbg`) | 쓸 이미지가 없을 때 | 단을 끝까지 채워야 한다. 비면 「만들다 만 배경」이 된다 |

①을 쓸 때 베일은 **`.veil.deep.top`**. `.full`을 쓰면 지면이 뭉개져서 깐 의미가 없다.
하단 절반에서 지면이 살아 있어야 인용 박스가 「그 위에 얹힌 발췌」로 읽힌다.

### ② CSS 지면 — `.paperbg`

근거 카드(04·05)는 **사진 대신 논문 지면을 배경으로 깐다.** 참고 레퍼런스가
「지면을 흐리게 깔고 그 위에 큰 카피」였는데, **실제 지면을 깔면 흐려도 복제다.**
그래서 **지면 구조 자체를 CSS로 그린다.** 글자가 아니라 「줄」이라 어느 배율에서도 안 읽히고,
100% 우리가 만든 것이라 권리 문제가 없다. `CLAUDE.md` 규칙 3(HTML/CSS로 만든다)과도 맞는다.

```html
<div class="paperbg">
  <div class="rh"><span>SKIN HEALTH AND DISEASE</span><span>VOL 6 · ISSUE 3 · 2026</span></div>
  <div class="ttl"><div class="l"></div><div class="l"></div></div>   <!-- 제목 2줄 -->
  <div class="auth"></div>                                            <!-- 저자 줄 -->
  <div class="pcols">
    <div class="pcol">…par…</div>   <!-- .par > .h(소제목) + .l(본문줄) ×n, 마지막 .l.s/.l.m -->
    <div class="pcol">…par + .fig + .tbl…</div>
  </div>
</div>
```

| 요소 | 값 |
|---|---|
| 지면 | `#F3EFE8` · `opacity:.32` · `filter:blur(.3px)` |
| 패딩 | `150px 58px 46px` — **상단 150px은 프레임(코너·마스트헤드) 회피용** |
| 러닝헤드 | 15 / 700 · 자간 .2em · 하단 1px 실선 |
| 본문 줄 | 높이 6px · 간격 9px · `rgba(28,24,21,.46)` |
| 소제목 줄 | 높이 7px · 너비 38% · `rgba(28,24,21,.72)` |
| 단 | 2단 · gap 38px · `overflow:hidden` |
| 도표 | 1px 테두리 + 축 2개 + 막대 6개 + 캡션 줄 |
| 표 | 상하 1px 괘선 + 3열 × 4행 |

- **단을 끝까지 채운다.** 문단이 모자라면 아래가 비어서 「만들다 만 배경」으로 보인다.
  `overflow:hidden`이 잘라주니 **넉넉히 넣고 자른다.**
- 러닝헤드는 **실제 인용한 저널명·권호**를 쓴다. 없는 저널을 지어내지 않는다.
- 베일은 `.veil.full`. 지면이 위아래로 다 깔려 있어 상단 베일로는 대비가 안 잡힌다.
- 인용 카드의 흰 박스가 지면 위에 얹히면서 **「발췌해 붙인 것」**처럼 읽힌다. 그게 이 조합의 목적이다.

### 인용 카드 (04번)

```html
<div class="quote">
  <div class="rlabel">RESEARCH</div>
  <q>핵심 문장 3줄. 원문의 결론을 우리말로 옮기되 뜻을 바꾸지 않는다.</q>
  <p class="src"><b>저자.</b><br>논문 제목(원어).<br><b>저널명</b> 연도;권(호):시작–끝쪽</p>
</div>
```

| 요소 | 값 |
|---|---|
| 박스 | `rgba(250,247,242,.90)` · 1px `rgba(28,24,21,.20)` · 라운드 4px · 패딩 42px |
| `RESEARCH` 라벨 | 21 / 700 · 자간 .28em · `--accent` |
| 인용문 | 44 / 700 · 행간 1.36 · 자간 -.03em · `--ink` · **3줄** |
| 출처 | 21 / 500 · `--muted`, 저자·저널만 700 `--body` |

- **배경 사진은 조용한 컷으로.** 인용문이 주인공이라 사진이 말을 걸면 안 된다.
- 베일은 `.veil.full`. 텍스트 블록이 길다.
- 인용문이 4줄이 되면 **문장을 줄인다.** 원문 요약이지 번역문이 아니다.

### 수치 카드 (05번)

```html
<div class="stat"><span class="n">51.2</span><span class="u">%</span></div>
<p class="statcap">숫자의 정체를 한 문장으로. <b>무엇의</b> 수치인지 반드시 밝힌다.</p>
<div class="mini">
  <div><b>27%</b>보조 수치</div> …최대 3개
</div>
<p class="cite">출처 한 줄</p>
```

| 요소 | 값 |
|---|---|
| 큰 숫자 | 158 / 700 · 자간 -.055em · `--ink` |
| 단위 | 56 / 700 · `--accent` |
| 설명 | 29 / 500 · `--body` |
| 보조 수치 | 46 / 700 `--ink` + 25 / 500 `--body`, **최대 3개** |

- **숫자 하나만 크게.** 네 개를 같은 크기로 늘어놓으면 아무것도 안 남는다.
- **분모를 반드시 적는다.** 「51.2%」가 아니라 「참가자 2,817명 시험의 기제군 51.2%」.
- 액센트는 단위 하나뿐이다. 보조 수치까지 붉게 하면 1항(카드당 2곳)이 깨진다.

### 지켜야 할 선

- **원문의 뜻을 바꾸지 않는다.** 요약은 하되 강도를 올리지 않는다.
- **연구 대상을 바꿔 읽지 않는다.** 질환 연구를 노화 관리 근거로 쓸 때는
  **캡션에 「질환 대상 연구」임을 명시**한다. (1호 회차가 그 사례다)
- **2차 문헌이면 그렇게 밝힌다.** 리뷰를 인용하면서 원 논문을 읽은 척하지 않는다.
- 근거 카드 두 장을 쓰는 대신 **본문 카드가 두 장 줄어든다.** 처방은 1~2개로 압축한다.
