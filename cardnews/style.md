# 카드뉴스 스타일 가이드 (인스타 매거진)

> 근거: `docs/03-design-system.md`(웜 뉴트럴 모노크롬 · 각진 · 풀블리드)에서 파생.
> 이 파일이 **디자인의 단일 기준**이다. 회차마다 다시 정하지 말고 이 문서를 따른다.
> 방법론 근거: `docs/08-cardnews-research.md` 핵심요약 2번(디자인을 문서로 고정해야 퀄이 일정해진다).

## 0. 절대 규칙

- **브랜딩은 앞뒤 표지에만.** (2026-08-03 변경 — 이전 "브랜드 언급 금지" 규칙 폐기)
  - **매 장 공통 프레임** (2026-08-05 변경): 좌상단 `▪ 코너명` + 우상단 `RIVEA MAG`.
    코너명은 재사용한다 — `제품` / `성분` / `루틴` / `생활`. 이게 시리즈감을 만든다.
  - 마지막 카드: 브랜드 아웃트로 1장
  - 구매 링크는 넣지 않는다. 저장·팔로우까지만.
- **판형**: 1080 × 1350 (4:5). 인스타 캐러셀 표준.
- **생성 방식**: 순수 HTML/CSS → Playwright 스크린샷 → PNG. 이미지 생성 AI로 카드를 만들지 않는다.
- **AI 슬롭 금지**: 보라/바이올렛 그라데이션, 흰 배경 둥근 카드 남발, 골드 액센트, serif 장식체, 네온, 글래스모피즘.

## 1. 컬러

| 역할 | 값 | 용도 |
|---|---|---|
| `--bg` | `#FFFFFF` | (v2에선 카드 배경 = 사진. 흰 배경 카드 없음) |
| `--ink` | `#1C1815` | 제목·강조 |
| `--body` | `#4A443E` | 본문 |
| `--muted` | `#8B8279` | 캡션·라벨·페이지번호 |
| `--line` | `#E5DFD6` | 헤어라인 |
| `--line-strong` | `#D0C8BD` | 강조 구분선 |
| `--accent` | `#C13B54` | **유일한 유채색.** 원칙 번호와 성분 라벨에만. |

- 액센트는 카드당 **2곳 이하**. 남발하면 무채색 기조가 무너진다.
- 사진 위 텍스트 대비는 **아이보리 베일**로 확보한다(4항 참고). 어두운 스크림 + 흰 텍스트는 쓰지 않는다.

## 2. 타이포그래피

**Pretendard** 단일 패밀리. 위계는 크기·굵기·색으로만. 굵기는 400/500/700만.

| 역할 | 크기 / 굵기 | 자간 | 행간 |
|---|---|---|---|
| 커버 헤드라인 | 98 / 700 | -0.04em | 1.18 |
| 커버 한 줄 | 31 / 500 | -0.01em | 1.4 |
| 라벨 (01 자외선) | 25 / 700 | 0.20em | 1 |
| 카드 헤드라인 | 80 / 700 | -0.035em | 1.22 |
| 정보 1줄 (성분명) | 33 / 500 | -0.01em | 1.45 |
| 정리 카드 리스트 | 37 / 700 | -0.02em | 1 |
| 페이지번호 | 23 / 600 | 0.16em | 1 |

- 헤드라인은 **2줄**로 끊는다. 3줄이 되면 문장을 줄인다.
- 줄바꿈은 의미 단위로 직접 넣는다(`<br>`). 자동 줄바꿈에 맡기면 어색해진다.

## 3. 형태·여백

- **라운드 4px**만 (페이지번호 받침 등). 둥근 사각형·pill 금지.
- **사진은 카드 전체 풀블리드.** 프레임·테두리·여백 없음.
- 텍스트 블록 좌우 여백 **80px**, 상단(또는 하단) **88px**.
- 구분선은 `1px solid rgba(28,24,21,.16)` 헤어라인만.
- 그림자 없음.

## 4. 카드 포맷 — **v2(사진 배경형)를 표준으로 쓴다**

레퍼런스: **`references.md` 참고.** 차원별로 담당 레퍼런스가 다르다
(포맷 @glowupmag / 시각언어 @aesop / 콘텐츠뼈대 @hwahae_official / 커머스 @todayhouse / 반례 @oliveyoung_magazine).

**모든 카드가 풀블리드 사진 배경이다.** 흰 본문 카드를 만들지 않는다.
카드 1장에 들어가는 텍스트는 **최대 3덩어리**:

```
라벨 (예: 01 자외선)        — 25px
헤드라인 2줄                 — 76px   ← 크게
본문 2~3문장 (2~3줄)         — 33px   ← 작게. 실제로 내용을 말한다
성분 1줄                     — 30px
```

- **큰 제목 ↔ 작은 본문의 대비가 이 포맷의 핵심.** 본문을 키워서 대비를 죽이지 말 것.
- 본문은 "아 이게 이런 내용이구나"까지만. **실천법·농도·주의사항은 카드에 넣지 않고 캡션으로.**
  카드가 사용설명서가 되면 스와이프가 멈춘다.
- 역할 분담: **카드 = 무엇을 알아야 하나 / 캡션 = 어떻게·왜·주의.**
  캡션이 카드 문장을 반복하면 안 된다. 캡션을 읽어야 실행이 가능해져야 한다.
- 총 **8장** 기본: 커버 1 + 원칙 5 + 정리 1 + **브랜드 아웃트로 1**.
- 정리 카드만 예외로 짧은 5줄 리스트(키워드만) 허용.

### 브랜드 아웃트로 카드 (마지막 1장, 유일하게 사진 없음)
사진 7장 뒤에 오는 **웜화이트 타이포 카드**. 캐러셀이 끝났다는 신호가 되므로 사진을 쓰지 않는다.
```
배경        #FAF7F2 + 상단 아주 옅은 화이트 방사 그라데이션 (평평해 보이지 않게만)
한글 한 줄  38px / 500 / --body      예) 당신이 푸르렀던 그 시절로
캐치프레이즈 144px / 700 / --ink     예) RE:BEAUTY  ← 콜론만 --accent
가운데 룰   92 × 1px, rgba(28,24,21,.26)
워드마크    46px / 700 / letter-spacing .44em / --accent(rivea-rose)
```
- 블록은 **정중앙이 아니라 top:45%** (광학 중심 — 아래 여백이 더 넓어야 안정적으로 보인다).
- 페이지번호를 넣지 않는다. 커버(`ISSUE 01`)와 아웃트로가 앞뒤 표지로 짝을 이룬다.

### 텍스트 대비 — 잉크 텍스트 + 아이보리 베일
밝은 웜톤 사진을 쓰므로 **흰 텍스트가 아니라 잉크(`--ink`) 텍스트**를 올린다.
(어두운 사진 + 흰 텍스트는 흔하고, 우리 웜 뉴트럴 기조와도 안 맞는다.)

가독성은 **아이보리 베일**로만 확보한다. 사진 분위기를 죽이지 않는 게 핵심:
```
기본  rgba(250,247,242, .68 → .46 → 0)   높이 58%
.deep rgba(250,247,242, .90 → .70 → 0)   어두운 사진에만
.thin rgba(250,247,242, .62 → 0)         높이 16%, 페이지번호 가독성용
```
> 초기에 .93/.86으로 깔았더니 사진이 크림색으로 뭉개졌다. **베일은 최소한만.**

- 텍스트는 사진의 **빈 영역 쪽에 앵커**한다(`.txt.top` / `.txt.bot`).
  피사체가 위쪽인 사진은 텍스트를 아래로. 위치 통일보다 사진과의 관계가 우선.
- 페이지번호는 옅은 아이보리 받침(4px)을 깔아야 질감 있는 배경에서도 읽힌다.

## 5. 사진 규칙

- 출처는 **Unsplash / Pexels만** (상업적 사용 허용, 출처표기 불필요). 큐레이션 사이트(핀터레스트·cosmos 등)는 원본 권리가 불명확하므로 사용 금지.
- **인물보다 분위기.** 정물·제품·텍스처·빛/그림자로 무드를 만든다. 얼굴은 넣어도 되지만 전부 사람 사진으로 채우지 않는다.
  → 부수 효과: 얼굴이 없으면 초상권·상품보증 제약이 사라져 재사용이 자유롭다.
- 인물을 쓸 경우: 45~65세 여성, 자연스러운 피부 질감. 과도한 리터칭·화려한 메이크업·K뷰티 광채 금지.
- **텍스트 앉힐 빈 영역이 있는 컷을 고른다.** 꽉 찬 사진은 아무리 예뻐도 못 쓴다.
- 밝은 웜톤(아이보리/베이지)으로 통일하면 7장이 저절로 한 세트가 된다.
- **다른 브랜드 제품의 로고·라벨이 읽히면 안 된다.** 읽히면 크롭으로 제외.
- **통일 그레이딩 필수** (이게 브랜드 느낌을 만든다):
  ```
  채도 0.58 · R×1.05+3 · B×0.93 · 대비 1.06 · 밝기 1.02
  ```
  출처가 달라도 이 그레이딩을 거치면 한 세트로 읽힌다.

## 5-B. 제품 추천 회차 전용 규칙 (2026-08-05 신설)

실제 브랜드 제품을 추천하는 회차는 아래를 전부 지킨다.

- **브랜드 로고 이미지를 쓰지 않는다.** 로고는 저작권물이면서 상표라 붙이면 협찬 오인 소지가 생긴다.
  1080px 카드에서는 로고보다 **제품명을 Pretendard로 크게 쓰는 게 더 잘 읽힌다.** 목적은 텍스트로 달성된다.
  (업계 관행은 프레스킷을 받아 `📷브랜드`로 출처 표기하는 것. 제휴 후에 실제 제품컷으로 교체한다.)
- **가격을 카드에 넣지 않는다.** 세일가는 수시로 바뀐다. 캡션도 "○만 원대"까지만.
- **협찬 아님을 커버와 캡션 두 곳에 명시한다.** 광고로 오인되면 표시광고법 이슈.
- **제품명에 이미 박혀 있는 성분만 카드에 쓴다.** 전성분표를 직접 확인하지 않았으면
  그 이상 단정하지 않는다. (예: `레티놀 0.1`, `우레아 12%`는 제품명에 있어 안전)
- **식약처 기능성 고시 문구는 등록 확인 없이 쓰지 않는다.**
  `주름개선`·`미백`은 고시 문구 → 확인 못 했으면 `주름 관리`처럼 일반 표현으로.
  단, 상품명에 이미 `탈모증상완화` 등이 박혀 있으면 그대로 쓸 수 있다.
- **자극 가능성이 있는 성분은 사용법을 캡션에 반드시 넣는다.** (레티놀: 밤에만·주 2~3회부터·자차 필수)
- 근거는 `products.md`에 **검증한 것 / 검증 못 한 것**을 나눠서 남긴다.
- 게시 직전 **재고·가격 재확인**.

## 6. 콘텐츠 규칙

- 커버 1 + 원칙 5 + 정리 1 + 브랜드 아웃트로 1 = **8장** 기본.
- 카드에는 **헤드라인 + 2~3문장 + 성분 1줄**. 실천법·농도·주의사항은 캡션.
- 각 카드에 성분 한 줄은 반드시 있어야 한다. 감상만 있으면 저장되지 않는다.
- 본문이 4줄을 넘으면 문장을 줄인다. 베일 유효구간(상단 베일의 80%)을 벗어나면 가독성이 깨진다.
  → `node veilcheck.mjs <에피소드>`로 검사. 내용이 많은 정리 카드만 `.veil.full`(전체 높이·저농도) 사용.
- 수치는 통용되는 범위만 쓰고 단정하지 않는다("~로 알려져 있다").
- **면책 문구는 캡션에 필수** (카드에는 넣지 않는다 — 카드는 최소한만): 일반 정보임 / 개인차 있음 / 질환·복용약 있으면 전문가 상담.
- 판매 유도·구매 링크 금지. 저장·팔로우 유도까지만. (브랜딩은 표지에서만 한다)
