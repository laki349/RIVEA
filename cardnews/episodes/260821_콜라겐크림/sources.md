## 2. 사실 근거

| 내용 | 출처 | 확인 |
|---|---|---|
| 피부 통과에 통상 500달톤 이하 (500달톤 룰) | Bos & Meinardi, Exp Dermatol 2000 (PubMed 10839713) | ✅ 원논문 존재 확인 |
| 천연 콜라겐 분자량 약 30만 Da | 다수 정리 문헌 일치 | ✅ 2회 교차 |
| 30만 ÷ 500 = 600배 | 단순 계산 | ✅ |
| 비타민C가 콜라겐 합성의 보조 인자 | 생화학 교과 수준의 통설 | ✅ 「알려져 있다」로 표기 |
| 자외선이 콜라겐 분해를 앞당김 | 광노화 일반 서술 | ⚠️ 수치 없이 방향만 서술 |

## 3. 다루지 않은 것

| 항목 | 이유 |
|---|---|
| 특정 콜라겐 크림 브랜드 | 지목하면 비방(별표5-2 카). 성분 일반론으로만 |
| 「저분자 콜라겐 ○달톤」 수치 | **제품별로 다르고 1차 확인이 안 된다.** 그래서 「표기 의무가 없다」까지만 |
| 먹는 콜라겐 | 건강기능식품 영역이라 화장품 계정이 다룰 선이 아니다 |
| 펩타이드 종류별 비교 | 근거 수준이 제각각. 이름을 나열하지 않았다 |

## 4. 조사 한계
- 500달톤 룰은 **경험칙**이고 예외가 있다. 카드에서 「대개 ~라고 알려져 있다」로 처리했다.
- 저분자 콜라겐의 실제 분자량 분포는 확인 못 했다. 그래서 **효과 여부를 판정하지 않고** 「확인 안 되면 기대치에서 뺀다」로 끝냈다.
