## 본문 (그대로 복붙)

아무 성분도 안 든 크림을 바른 그룹도 좋아졌습니다.

임상시험의 「기제군」— 유효 성분을 뺀 크림만 바르는 대조군이에요.

· 염증성 병변 51.2% 감소 (2,817명)
· 홍조 27% 감소 · 색소침착 44.9% 개선

리뷰의 결론은 이렇습니다. 기제군이 활성 성분군 효과의 절반 이상을 자주 낸다고요.
(여드름·주사 같은 질환 연구입니다. 화장품 시험이 아니에요)

그러니까 「좋아졌다」의 절반은 성분이 아니라 잘 바른 겁니다.

10만원 쓰기 전에 이것부터요.

1️⃣ 아침 — 세안 → 보습 → 자외선 차단
　 손가락 두 마디, 흐린 날도 거르지 않기

2️⃣ 저녁 — 세안 후 3분 안에
　 마지막은 크림으로 덮어 잠그기

3️⃣ 성분은 그다음
　 위 둘을 12주 지켰는데도 그대로일 때

살까 말까 할 때 이 다섯 줄만 보세요.

· 기본이 비었다 → 지금은 사지 않는다
· 4주째다 → 아직 판정하지 않는다
· 12주째 그대로다 → 이때 성분을 올린다
· 따갑거나 붉어졌다 → 횟수부터 줄인다
· 좋아진 것 같다 → 사진으로 확인한다

사진은 주 1회, 같은 조명·같은 각도로. 느낌은 그날 컨디션을 따라가지만 사진은 안 그래요.

저장해두고 살 때 꺼내 보세요. 근거 붙인 회차는 계속 올립니다.

⚠️ 일반적인 정보이고 개인차가 있습니다. 인용 연구는 질환 대상이며 특정 제품의 효과를 말하지 않습니다. 자체 설문은 32명(50대 24·40대 4) 기준입니다.

## 이 회차의 논지

> **「좋아졌다」는 느낌은 성분의 증거가 아니다. 기본을 채운 뒤라야 판정이 성립한다.**

| 카드 | 역할 | 내용 |
|---|---|---|
| 01 | 문제 제기 | 아무것도 안 든 크림도 좋아졌다 |
| 02 | 공감 | 우리 설문 23/32 (72%) |
| 03 | 손해 | 느낌으로 판정하면 두 번 잃는다 |
| 04 | **근거 · 인용** | 리뷰 원문 결론 + 저자·저널·권호 |
| 05 | **근거 · 수치** | 기제군 51.2% + 보조 수치 3개 |
| 06 | 해석 | **중요한 건 무엇을 바르느냐가 아니다** — 빠뜨리지 않는 것 |
| 07 | 행동 | **아침 / 저녁 / 그다음** 세 줄로 명시 |
| 08 | 정리 + CTA | 실행 체크리스트 5줄 → 「성분은 이 다음」 |

### 이 포맷을 만든 이유

기존 회차는 **주장 → 처방**이었다. 주장의 출처가 우리뿐이라 「그렇대요」에서 멈춘다.
리서치 포맷은 **04·05번 두 장을 근거에 통째로 쓴다.** 두 장을 비우는 대신
「이 계정은 출처를 댄다」가 남는다. `카피공식.md`가 말한 권위부여를 논문으로 하는 방식이다.

### 쓰지 않은 것 (규제선)
- ❌ **논문 지면 캡처 · 연구자 사진** — 저작물이고 초상권이다. 인용을 재조판했다
- ❌ 질환 연구를 노화 관리로 바꿔 읽기 — **캡션에 「질환 대상 연구」임을 명시**했다
- ❌ 특정 제품 언급 — 리뷰의 결론은 제품이 아니라 기본 케어에 관한 것이다
- ⚠️ 카드 05의 네 숫자는 전부 **기제(위약)군** 수치다. 카드 안에 그렇게 적었다
