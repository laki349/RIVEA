# RIVEA(리베아) — 파운데이션 (사업·유저·IA·유저저니)

> 작성일: 2026-07-28 (갱신)

## 1. 한 문장 정의

> **리베아는, 중년 여성이 겪는 "피부·두피 고민"을 축으로 여러 브랜드의 홈케어 기기·화장품을 묶어 파는 중개형(입점) 이커머스 앱이다.**

- **형태**: **모바일 앱 UX**. 데스크탑에서도 **중앙 고정 모바일 프레임**으로 보인다(에이블리·지그재그 식). → 웹 반응형이 아니라 **앱 셸 + 하단 탭바**가 기본 골격.
- **거래 모델**: 중개형 마켓플레이스. 자사 브랜드가 아니라 **입점 브랜드** 상품 판매. 장바구니·결제까지 실제 커머스.
- **차별점 1 — 고민 우선(concern-first)**: "세럼/토너" 제품 분류가 아니라 **"기미·잡티 / 주름·탄력 / 건조 / 자외선 / 모공 / 두피·헤어 / 이너뷰티"** 같은 *실제 고민*을 탐색의 축으로 삼는다. → 홈의 관문.
- **차별점 2 — 루틴 세트**: **디바이스 + 그에 맞는 화장품**을 묶은 *루틴 관리 세트*. → **리베아's Pick** 탭 + 홈 히어로로 전면 노출.
- **포지셔닝**: 저가·트렌디가 아니라 **차분하고 정제된 프리미엄**. 40대+가 "믿고 사는" 신뢰감이 자산.

## 2. 타깃 유저 (두 층을 동시에)

### 페르소나 A — "관리 입문 40대" (가이드가 필요한 층)
- 이제 막 안티에이징·기미 관리에 관심. **뭘 사야 할지 모른다.**
- 니즈: "내 고민에 맞는 걸 **골라줘**." 성분보다 **결과·후기·추천**을 신뢰.
- 진입로: **홈의 고민 배너 / 리베아's Pick 루틴 세트**(가이드형).

### 페르소나 B — "성분·기능 아는 40·50대" (검증하는 층)
- 관리 경험 많고 성분·기능을 따진다.
- 니즈: **비교·성분·리뷰·브랜드 신뢰도**. "왜 이게 나은지" 근거를 원함.
- 진입로: **카테고리 탭·브랜드·검색으로 바로 탐색**(검증형).

> **설계 함의**: 앱은 두 진입로를 **동시에** 연다 — 홈(고민·큐레이션, A) + 카테고리/검색(제품·비교, B). 어느 한쪽으로 몰지 않는다.

### 연령 특성에서 오는 UX 제약 (타협 불가)
- 본문 **16px 이상**, 버튼·터치 타깃 넉넉히(≥44px).
- **명도 대비 충분히**(WCAG AA 4.5:1↑). 저대비 연회색 텍스트 남용 금지.
- 복잡한 제스처·화려한 모션 지양. **명료함 > 세련됨**.
- 상품 정보(성분·용법·배송)는 **접지 말고 펼쳐** 보이는 걸 우선.

## 3. 앱 셸 & 내비게이션

### 폼팩터
- **모바일 프레임**(권장 폭 390–430px)을 데스크탑에서도 중앙에 고정 렌더.
- 상단 **앱바**(제목/뒤로/검색/장바구니) + 하단 **탭바**가 상시 골격.

### 하단 탭바 (5개, 확정)
```
[ 홈 ]   [ 카테고리 ]   [ 리베아's Pick ]   [ 찜 ]   [ 마이페이지 ]
```
| 탭 | 역할 |
|---|---|
| **홈** | 고민 배너 + **리베아's Pick 루틴 히어로** + 베스트·신상 + 브랜드 레일 |
| **카테고리** | 첨부 레퍼런스형 2단 브라우징(좌 레일 + 우 세부 목록) |
| **리베아's Pick** | 루틴 세트·큐레이션 모음(차별화 상품을 독립 탭으로 격상) |
| **찜** | 위시리스트 |
| **마이페이지** | 주문내역·리뷰·설정 |

## 4. 정보 구조 (IA / 사이트맵)

```
앱 셸 (하단 탭바)
│
├─ 홈 (/)
│    - 고민 배너(→ /concern/[slug])          ← 차별점1의 관문
│    - 리베아's Pick 루틴 히어로(→ /routine)   ← 차별점2 노출
│    - 오늘의 추천 / 베스트 / 신상
│    - 브랜드 레일(→ /brand)
│
├─ 카테고리 (/category)
│    상단 탭(제품군) + 좌 레일(세부군) + 우 목록(품목)   ← 첨부 레퍼런스형
│    제품군: 스킨케어 · 디바이스 · 기미커버 메이크업 · 마스크팩
│            · 선케어 · 클렌징 · 두피·헤어 · 이너뷰티
│    └─ /category/[slug]   고민 필터 + 성분 필터 + 정렬(추천·인기·신상·가격·리뷰)
│
├─ 리베아's Pick (/pick)
│    루틴 세트 큐레이션(고민별·상황별)
│    └─ /routine/[id]   구성품·사용 순서·개별가 대비 세트가
│
├─ 고민 탐색 (홈 배너 진입)
│    └─ /concern/[slug]  기미·잡티 / 주름·탄력 / 건조 / 자외선 / 모공 / 두피·헤어 / 이너뷰티
│         - 고민 설명(왜 생기나/어떻게 관리) + 추천 루틴세트 + 관련 단품
│
├─ 브랜드(입점사)
│    ├─ /brands        입점 브랜드 목록
│    └─ /brand/[slug]  브랜드관: 소개·신뢰지표·상품
│
├─ 상품 상세
│    └─ /product/[id]  갤러리 / 구매패널 / 성분·용법 / 리뷰 / 브랜드 비교표
│
├─ 커머스 흐름
│    ├─ /cart          장바구니
│    ├─ /checkout      주문·결제
│    └─ /order/[id]    주문 완료·조회
│
└─ 찜(/wish) · 마이페이지(/mypage)
```

> **미결(다음에 확정)**: 카테고리 탭 **상단 축**을 (a) 제품군 단일로 갈지, (b) `고민별 / 카테고리별` 2축으로 둘지.
> 현재 문서는 (a) 제품군 단일 + 고민 탐색은 홈 배너로 분리 안으로 잡음. 홈이 고민 진입을, 카테고리가 제품 브라우징을 담당(역할 분리).

## 5. 핵심 유저 저니

### 저니 1 — 페르소나 A (가이드형, 주 전환 경로)
```
홈 → "요즘 기미가 고민이에요" 고민 배너 클릭
  → /concern/기미  (기미가 왜 생기나 + 추천 루틴 세트 3종)
  → 루틴 세트 상세(디바이스+세럼+선크림, 개별가 대비 세트가)
  → 장바구니 → 결제 → 완료
```
또는 홈 → **리베아's Pick 탭** → 루틴 세트 바로 진입.

### 저니 2 — 페르소나 B (검증형)
```
홈/하단탭 → 카테고리(스킨케어) 또는 브랜드관
  → 성분/고민 필터 + 리뷰순 정렬
  → 상품 상세에서 브랜드 비교표·성분·리뷰 확인
  → 장바구니 → 결제
```

### 저니 3 — 브랜드 신뢰 경로
```
상품 상세 → 브랜드명 클릭 → /brand (입점 브랜드 신뢰지표·다른 상품)
```
중개형이라 **브랜드 신뢰**가 이탈 방지의 핵심. 브랜드를 숨기지 않고 전면에.

## 6. 화면 우선순위 (구현 순서 제안)

| 순위 | 화면 | 이유 |
|---|---|---|
| 1 | 앱 셸 + 홈 | 탭바 골격 + 두 진입로 관문 |

| 6 | /cart → /checkout | 커머스 완결 |
| 7 | /brand · /wish · /mypage | 신뢰·재방문 |

## 7. 디자인 원칙 (연구 문서에서 확정)

1. **고민 언어로 말한다** — 카피가 "세럼 30% 할인"이 아니라 "기미가 올라오기 시작했다면".
2. **비교가 곧 가치** — 상세에 브랜드 비교표. 중개형의 존재 이유.
3. **AI 티 회피** — 웜크림+serif+골드는 *AI 기본 팔레트 중 하나*라 기시감. → 타이포 페어링·액센트 색으로 RIVEA 개성을 심는 게 다음 과제(→ 02-design-system).
4. **중장년 가독성 최우선** — 16px+, 대비 충분, 정보는 펼쳐서.
5. **실제 콘텐츠·실제 상태** — Lorem ipsum 금지. 빈/로딩/에러 상태까지 설계.
