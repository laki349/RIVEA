# RIVEA(리베아) — 화면 와이어프레임 (구조·위계)

> 작성일: 2026-07-28
> 목적: 스타일 없이 **레이아웃·위계·기능만** 못박는다. (와이어 = 뼈대, 색/폰트는 02-design-system에서)
> 전제: 모바일 프레임(폭 390–430px), 상시 하단 탭바. 각 화면은 "핵심 요소 1개"를 정하고 그걸 가장 크게.
> 표기: `[블록]`, `⬚`=이미지 슬롯, `▸`=강조, 들여쓰기=포함관계.

---

## 0. 앱 셸 (모든 화면 공통 골격)

```
┌───────────────────────────┐  ← 모바일 프레임(데스크탑 중앙 고정)
│ [앱바] 뒤로/제목   검색 장바구니 │  ← 상단, 화면마다 내용 다름
├───────────────────────────┤
│                           │
│      (화면 콘텐츠)          │  ← 스크롤 영역
│                           │
├───────────────────────────┤
│ 홈  카테고리  리베아'sPick  찜  마이 │  ← 하단 탭바(상시 고정, 5개)
└───────────────────────────┘
```
- 하단 탭바: 아이콘+라벨, 현재 탭만 진하게(브라운/차콜), 나머지 흐리게. 터치 타깃 ≥44px.
- 앱바 높이 고정. 홈만 로고, 나머지는 뒤로+제목.

## 1. 홈 (탭: 홈) — 핵심 요소 = "추천 제품 히어로(풀블리드)"

> 개편(사용자 지시): 상단 고민 칩 제거(카테고리 탭이 대체). 배경 흰색. 히어로는 여백 없이 **꽉 채운다**.
> 고민-우선 차별화는 **리베아's Pick 루틴**(고민 언어 카피)과 카테고리 내 고민 필터로 흡수.

> v4 개편(design-review HIGH 2건 반영): ①고민 진입 동선 복원 ②상단 프로모 2연타 해소(루틴을 섹션으로).
```
[앱바]  RIVEA(로즈 로고)            🔍  🛒
─────────────────────────────────────
[고민으로 찾기]  라벨 + 가로 퀵 진입(56px 각진)   ← 차별화 진입 복원
   기미·잡티 · 주름·탄력 · 건조 · 자외선 · 두피·헤어 …  → /concern/[slug]
─────────────────────────────────────
▸[히어로 — 추천 제품]  풀블리드, 빽빽하게 채움     ← 화면 주인공
   ⬚ 사진이 배너 가득 + 오버레이 카피 + 카운터(3/12)
   (정체불명 썸네일 제거 — 모호한 탭 대상 없음)
─────────────────────────────────────
[리베아's Pick]  섹션(제목+전체보기) + 가로 루틴 카드
   ← 경쟁 배너 아님. 200px 각진 카드, 여러 루틴 수용
─────────────────────────────────────
[50대가 지금 많이 봐요]  연령대 인기 모듈 (사회적 증거)
   부제 "김서연님과 비슷한 연령대 · 이번 주 기준"
   연령 토글 40/50/60대이상 + 제품|루틴 전환
   랭킹 넘버 카드 + "이번 주 N명이 봤어요"
   ※ 카피 존중형 — "또래" 금지, 연령 명시. 중년 신뢰 레버.
─────────────────────────────────────
[베스트]  2열 직사각 그리드 / 랭킹 번호(1·2·3…)
   ⬚ / 브랜드 / 상품명 / 가격(할인 시 로즈 숫자)
─────────────────────────────────────
[신상]  가로 스크롤 · [브랜드]  레일 → /brand/[slug]
─────────────────────────────────────
[하단 탭바]
```
- 각 블록 한 가지 일: **고민 진입 → 추천 히어로 → Pick 섹션 → 베스트 → 신상/브랜드**.
- 배경 흰색 + 헤어라인 구분. 히어로만 풀블리드로 시선 잡기.
- (미해결·다음: 로즈 색 남용 정리, 카테고리 선택표시 통일, 결제 동의 기본해제, 터치타깃 44px — design-review MEDIUM/POLISH)

## 2. 고민 상세 /concern/[slug] (홈 배너 진입) — 핵심 = "추천 루틴 세트"

```
[앱바]  ← 뒤로   "기미·잡티"        🛒
─────────────────────────────────────
[고민 인트로]
   ⬚ 배너
   "왜 지금 기미가 올라올까?"          ← 공감/설명 (2~3줄, 16px+)
   관리 포인트 3가지 (아이콘+한 줄)
─────────────────────────────────────
▸[이 고민엔 이 루틴 (N)]               ← 주인공, 개수 표시
   **가로 스크롤** 루틴 카드(216px, 다음 카드 peek + 화살표)
   ⬚ / PICK 라벨 / 세트명 / 세트가  → 루틴 여러 개 무한 수용
   (세로 고정 1개 금지 — 루틴 늘면 관련단품 자리 안 밀리게)
─────────────────────────────────────
[관련 단품]  필터칩(제품군) + 상품 그리드 2열
   ⬚ / 브랜드 / 상품명 / 가격 / ★
─────────────────────────────────────
[이 고민 브랜드 추천]  브랜드 레일
─────────────────────────────────────
[하단 탭바]
```
- 페르소나 A를 위한 화면: 설명 → 검증된 세트 → (원하면) 단품 비교. **읽기 쉬운 큰 본문**.

## 3. 리베아's Pick (탭: 리베아's Pick) — 핵심 = "루틴 세트 큐레이션"

```
[앱바]  리베아's Pick               🔍 🛒
─────────────────────────────────────
[큐레이션 소개]  "에디터가 고른 루틴" 한 줄
─────────────────────────────────────
[필터 칩]  고민별 · 상황별(입문/집중/데일리) · 가격대
─────────────────────────────────────
[루틴 세트 리스트]  세로 큰 카드
   ⬚ 비주얼
   세트명 / 한 줄 설명(고민 언어)
   구성 뱃지: 디바이스 · 세럼 · 선크림 …
   개별가 취소선 → 세트가 · 할인율
   [세트 담기]  [자세히]
─────────────────────────────────────
[하단 탭바]
```

### 3-1. 루틴 상세 /routine/[id]
```
[앱바] ← 뒤로  세트명                🛒
─────────────────────────────────────
⬚ 갤러리(구성품 한 컷 + 개별 컷)
세트명 / 세트가(개별가 대비 절감액 강조)
─────────────────────────────────────
▸[사용 순서]  1→2→3 스텝(번호+제품+한 줄 용법)  ← 주인공
─────────────────────────────────────
[구성품]  각 상품 행: ⬚ 브랜드/상품/개별가 → 상품상세 링크
[개별 구매도 가능]  체크로 일부만 담기(옵션)
─────────────────────────────────────
[리뷰]  세트 리뷰 요약(★ 분포 + 대표 후기)
─────────────────────────────────────
[하단 고정 CTA]  세트가 ₩○○  [장바구니]  [바로구매]
```

## 4. 상품 상세 /product/[id] — 핵심 = "구매 결정(비교·성분·리뷰)"

```
[앱바] ← 뒤로   브랜드명             🛒
─────────────────────────────────────
⬚ 상품 갤러리(스와이프)
─────────────────────────────────────
브랜드명(→브랜드관) / 상품명
가격(정가 취소선 → 판매가) / ★평점·리뷰수 / N명이 보고 있어요
[고민 태그]  기미·잡티 등(→ concern)
─────────────────────────────────────
[혜택·배송 정보 행]  (올영 참고, 라벨+값+›, 선 구분)
   결제혜택: 카드사 즉시할인 최대 10%
   적립: 리베아 포인트 1% 적립
   배송: 2,500원 · 2만원 이상 무료 / 평균 2~3일
   빠른배송: 지금 주문 시 내일 도착 가능
─────────────────────────────────────
▸[브랜드 비교표]                       ← 중개형의 핵심 가치
   이 상품 vs 같은 고민 대안 2~3
   행: 가격 · 핵심성분 · 용량 · 평점 · 특징
─────────────────────────────────────
[성분·용법]  펼침 없이 노출(중장년 배려)
   전성분 / 사용법 / 주의
─────────────────────────────────────
[리뷰]  ★분포 + 사진리뷰 + 정렬(도움순)
─────────────────────────────────────
[함께 쓰면 좋은]  루틴 세트/연관 단품 레일
─────────────────────────────────────
[하단 고정 CTA]  판매가 ₩○○  ♡찜  [장바구니] [바로구매]
```

## 5. 카테고리 (탭: 카테고리) — 첨부 레퍼런스형 2단

```
[앱바]  카테고리                    🔍 🛒
─────────────────────────────────────
[상단 탭(제품군, 가로 스크롤)]  ← 확정: 제품군 단일 축(a)
  스킨케어 · 디바이스 · 기미커버 · 마스크팩 · 선케어 · 클렌징 · 두피·헤어 · 이너뷰티
─────────────────────────────────────
┌──── 좌 레일 ────┬──── 우 세부 목록 ────┐
│ (선택 제품군의   │  ▣ 세부군 A          │
│  세부군 세로     │    품목 · 품목 · 품목 │
│  리스트, 현재    │  ▣ 세부군 B          │
│  선택 강조)      │    품목 · 품목 …     │
│  · 세부군 A      │                     │
│  · 세부군 B      │  → 품목 탭 →         │
│  · 세부군 C      │     /category/[slug] │
└─────────────────┴─────────────────────┘
[하단 탭바]
```

### 5-1. 카테고리 목록 /category/[slug]  (개편: 가로 2단 탭)
> 사용자 지시: 상단을 박스로 나누지 말고 **가로 스크롤 2단 탭**으로(무신사/올영식).
```
[앱바] ← 뒤로   "스킨케어"                🔍 🛒
─────────────────────────────────────
[1단 대분류 탭]  가로 스크롤, 선택만 세로바+굵게
   스킨케어 · 디바이스 · 기미커버 · 마스크팩 · 선케어 …
─────────────────────────────────────
[2단 소분류 탭]  연회색 띠, 선택만 굵게
   전체 · 세럼·앰플 · 에센스 · 크림 · 토너 · 아이케어 …
─────────────────────────────────────
[필터·정렬 줄]  고민·성분·가격(작은 칩)        인기순 ▾
─────────────────────────────────────
[상품 그리드 2열, 직사각]
   ⬚ / 뱃지 / 브랜드 / 상품명 / 로즈할인율+가격 / ★리뷰수 / ♡
   (스크롤 페이지네이션)
─────────────────────────────────────
[하단 탭바]
```
- 이 2단 가로탭이 리스팅의 표준 상단. 카드형/박스형 필터는 지양.

## 6. 커머스 흐름 (요약 와이어)

- **장바구니 /cart**: 브랜드별 그룹(배송 단위) → 상품 행(수량·가격·삭제) → 하단 합계+[주문].
- **결제 /checkout**: 배송지 → 상품 요약 → 결제수단 → 최종 금액 → [결제하기]. *결제/카드정보 입력은 실제 결제 연동 전까지 더미.*
- **주문완료 /order/[id]**: 완료 메시지 + 주문번호 + 배송조회 안내.

## 7. 보조 화면 (요약)
- **찜 /wish**: 담은 상품 그리드 + 품절/가격변동 뱃지.
- **마이페이지 /mypage**: 주문내역 · 리뷰관리 · 찜 · 설정. (로그인 전엔 로그인 유도.)
- **브랜드관 /brand/[slug]**: 브랜드 소개·신뢰지표(입점기간/평점/배송) + 상품 그리드.
- **검색**: 최근검색어 · 인기고민 · 자동완성 → 결과는 /category 목록 재사용.

## 8. 공통 상태(빈/로딩/에러) — 설계에 포함 (AI티 탈출 원칙)
- **로딩**: 스켈레톤(카드 형태 유지).
- **빈 상태**: "아직 담은 상품이 없어요" + 추천 CTA. (막연한 회색 박스 금지)
- **에러**: 재시도 버튼 + 사람 언어 메시지.
