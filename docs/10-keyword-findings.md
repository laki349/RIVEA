## 1. 병용·조합·순서 = 0건

1,382개 중 「같이」「함께」「순서」「병용」「궁합」「동시」「겹치」가 포함된 키워드 **0개**.

→ **확정**: 사람은 자기가 겹치게 쓰는지 모르고, 모르니까 검색하지도 않는다(unknown unknown).
→ **설계 함의**: 병용 판정을 진입점에 두면 아무도 안 온다. 진입은 증상어로, 병용은 진입 후에.

```
증상어로 들어온다   "기미크림"        ← 월 20,080 · 획득
      ↓
쓰는 걸 등록한다    내 화장대          ← 여기서 처음 데이터가 생김
      ↓
겹치는 걸 알려준다   병용 판정          ← 월 0 · 유지
```

## 2. 노화 추상어는 죽었고, 증상어 + 제품형이 산다

| 죽은 것 | 월 검색 | | 산 것 | 월 검색 |
|---|---:|---|---|---:|
| 노화방지 | 290 | | 기미크림 | **20,080** |
| 안티에이징 | 1,590 | | 기미 | 13,600 |
| 기미없애는방법 | 190 | | 기미없애는법 | **13,250** |
| 50대화장품 | 280 | | 기미패치 | 6,230 |
| 40대화장품 | 260 | | 색소침착 | 4,220 |

**「기미없애는방법」190 vs 「기미없애는법」13,250 — 한 글자 차이로 70배.**
문장형을 안 치는 게 아니라 **정확한 관용 표현 하나만** 친다. 키워드는 감으로 찍으면 안 된다.

**연령 명시형은 사실상 0이다.** 자기 나이로 화장품을 찾지 않는다.
→ `docs/01` 원칙 1(고민 언어)은 맞지만, 카피에 "40대·50대"를 쓰면 안 된다.

## 4. 진짜 경쟁자는 피부과다 (월 310,035회 · 전체의 17.6%)

| 키워드 | 월 검색 | 키워드 | 월 검색 |
|---|---:|---|---:|
| 리쥬란 | **63,900** | 흑자제거 | 9,940 |
| 피코토닝 | 21,230 | 기미잡티레이저 | 7,570 |

**리쥬란 하나가 뷰티디바이스 전체(21,400)의 3배다.**
기미로 고민하는 사람은 홈케어보다 피부과를 먼저 검색한다.

**→ IR덱 09번 경쟁 구도표에 「피부과 시술」 행이 없다.** 올리브영·화해·지그재그만 있다.
"피부과랑 경쟁하는 거 아닌가요"에 지금 답이 없다.

**→ 동시에 기회다.** 시술은 회당 10~20만원이고 반복해야 하는데,
**시술 사이에 뭘 발라야 하는지는 아무도 안 알려준다.**
`rules.ts`의 「고주파 쓴 날은 장벽부터 채워야 해요」(r8)가 정확히 그 자리다.
