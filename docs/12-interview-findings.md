## 0. 요약 — 세 줄

1. **새 발견은 「캡쳐해놓고 못 찾는다」 하나다.** 40대 2명이 독립적으로, 행동 진술로 말했다.

   진입점에 두면 안 된다는 결론이 두 번째 독립 근거를 얻었다.
3. **40대 타깃 결론(07번·10번)이 유지된다.** 다만 40대 4명 중 1명은 「불편함이 없다」고 답했다.
   전원의 문제가 아니다.

## 2. 확실한 신호 — 2명 이상 독립 언급

### 2-1. 「캡쳐는 뜨는데 다시 못 찾는다」 — B, D **[행동]**

이번 인터뷰의 유일한 신규 발견이자 가장 값어치 있는 대목.

```
인스타에서 제품 발견  →  스크린샷  →  갤러리에 묻힘  →  못 삼
                                        ↑ 여기서 끊긴다
```

- 의향이 아니라 **이미 하고 있는 행동의 실패**다.
- 40대 4명 중 2명. 인스타를 정보 경로로 쓰는 사람은 2명이었으므로 **해당자 2/2**.
- 설계 함의: 발견 시점의 저장 → 재발견 경로. 「내 화장대」의 진입 동기가 될 수 있다.

> ⚠️ 2명은 아직 결론이 아니다. §7 검증 항목 1번.

### 2-2. 단계 묶음 / 순서 — F, B, (엄마) **[행동+요청]**

세 방향에서 각각 나왔다.

- F: **"상품을 1단계 2단계 상품끼리 묶어서 볼 수 있게끔 하면 좋겠다"** ← 직접 요청
- B: "순서가 있고 중요하다" / **"사용법도 잘 기억이 안 난다"**
- 조사자 모친: "너무 많이 바르면 흡수가 잘 안 된다"

→ 낱개 제품이 아니라 **루틴 단위 번들**. `10번`의 "진입은 증상어, 병용은 진입 후"와 정합.

### 2-3. 자녀에게 **지정해서** 사달라고 한다 — A, B, C (3/6) **[행동]**

- A: "부탁해서 사다준 적 있음" / 딸이 사준 건 리쥬란 탄력 제품
- B: 딸이 톤에 맞춰 사줌
- C: 아들에게 수분크림·기미앰플을 **직접 지정**, "선물할 때 이걸로 사줘"
- 공통: **"20대는 정확히 모르니까 지정해서 준다"**

→ 구매자 ≠ 사용자. 위시리스트/선물하기는 기능이 아니라 **획득 채널**일 수 있다.
   (딸이 앱을 깔게 되는 경로 — 40대+ 광고 단가를 우회한다)

### 2-4. 노안 → 큰 글씨 — 공통 코멘트 + D **[행동]**

D는 **본인이 헤어 디바이스를 판매하면서** 중년 고객용으로 큰 글씨 사용법 책자를 따로 껴서 발송했다.
추측이 아니라 검증된 시장 대응이라 무게가 다르다.

### 2-5. 퀸잇 인지 6/6, 전원 광고로 인지

- "내가 안다고 하니까 어떻게 아냐고 되물을 정도"
- 최근 필라 할인쿠폰으로 실사용

→ `10번`의 「퀸잇 월 16.7만 회」와 일치. **중년 전용 포지션 자체는 통한다**는 증거이자,
   획득이 광고비 싸움이 된다는 경고.

## 3. 반박된 것 — 성분 충돌

**6/6이 성분 충돌이라는 개념 자체를 모른다.**

| 발언자 | 발언 |
|---|---|
| 공통 | "성분은 고려 안 함. 충돌하는 성분에 대한 인식 자체가 없음" |
| C | "좋다 하면 겹치든 말든 막무가내로 바른다" |
| D | "성분 충돌이 될 거라는 생각을 잘 못한다" |
| B | "성분은 써봐야 아는 것 같다. 얼굴에 직접 발라봐야 안다" |
| B | "웬만하면 기초라인을 따라 바르니 충돌하지는 않는 것 같다" |

동시에 **화해(화장품 성분 앱)는 D·E가 이미 알고 있다.** 묻지도 않았는데 먼저 언급했다.

→ 성분 정보 수요가 없는 게 아니라, **「충돌」이라는 프레임을 이해하지 못한다.**
→ `10번` 「병용 검색량 0건」의 대면 확인. `rules.ts`는 **획득 훅이 될 수 없다**(재확인).
→ 성분은 뒤에서 돌리고, 앞에서는 **"이 순서로 바르세요"로 번역**해서 보여준다.

## 4. 유일한 반증 — E (예림이모)

> **"제품 살 때 불편함은 솔직히 없었다. 워낙 정보가 넘쳐나니까."**

나머지 5명이 예의상 긍정한 것과 달리 이 사람은 진짜 답을 했다. **40대 4명 중 1명**이다.

→ 우리가 푸는 문제는 **전원의 문제가 아니라 일부의 문제**다. 침투율 기대치를 여기에 맞춘다.
→ 이 반증을 지우지 말 것. 다음 인터뷰에서 「불편함 없음」 응답 비율을 계속 센다.

## 5. 40대 vs 50대 — 07번 문서의 분리가 재현됐다

| | 40대 (B·D·E·F) | 50대 (A·C) |
|---|---|---|
| 구매 동기 | 루틴 유지 | 광고 반응 / 가격 |
| 정보 경로 | 인스타 → 캡쳐 → **유실** | 유튜브·쿠팡 광고 → 즉시 진입 |
| 순서 개념 | 있음 | 없음 (막 바름) |
| 우리 앱 반응 | "루틴 플랫폼이면 쓴다" | A: "가격 메리트 있어야" / C: "궁금해서 무조건 들어간다" |

**50대 2명은 서로 정반대인데 둘 다 우리 고객이 아니다.**

- **A는 가격에서 막힌다.** "중년 이상 타깃 값어치는 검색은 하지만 구매는 하고 싶지 않다.
  가격 메리트가 없다." → 중개형 마켓플레이스에서 가격 우위가 없으면 리텐션이 안 된다.
- **C는 이미 다 산다.** 광고만 보고 겹치든 말든 전부 구매. 우리가 더할 가치가 없다.

→ **초기 타깃 = 40대 유지** (07번·10번과 동일 결론, 세 번째 독립 근거).
→ 단 3:3 표본에서 나온 분리라 세대 차이인지 개인차인지는 미확정. §7 검증 항목 2번.

## 6. 우리 앱에 대한 직접 피드백

### 6-1. 홈이 정체성을 못 드러낸다 — D **[가장 아픈 지적]**

> **"광고를 보고 온 상황이면 모르겠으나, 홈화면에 딱 40·50대를 위한 앱이라는 게 잘 모르겠다."**

공통 코멘트와 같은 말:
> "아이콘을 좀 크게 해서(고민으로 찾기) 확실하게 브랜드 정체성을 드러내는 게 좋겠다."

→ 즉시 조치 가능. 최근 커밋(`421fe7d` 진입점 정리, `8c84665` 진입점 정리)의 연장선.

### 6-2. 피부 설정 기반 추천 — 공통 **[긍정]**

> "피부 타입이나 민감한 자신의 피부를 설정해놓으면 그거에 따라 제품을 뜨게 하는 방안이 상당히 괜찮다."

→ `Onboarding.tsx` + 고민 설정의 방향이 맞다는 확인. (단, 의향 진술이므로 가중치 낮게)

### 6-3. 영상 필요 — B **[요청]**

> "제품 사용법 같은 게 영상으로 첨부되어 있으면 너무 좋겠다. **텍스트로만 접해서 이게 분간이 잘 안 된다.** 사용법도 잘 기억이 안 난다."

→ 노안(§2-4) + 사용법 미기억이 겹치는 지점. 상세 페이지에 영상 슬롯.

### 6-4. 가격 표시 방식 — A **[행동]**

> "할인율 슬래시하고 정가에서 할인한다는 걸 보여줘야 더 사게 된다."

→ 앵커링 UI가 전환율에 직접 영향. 마켓플레이스 가격 컴포넌트 설계 시 반영.

## 7. 놓치면 안 될 부수 신호

- **객단가 여력**: 30–40만원대 기기를 이미 쓰는 사람이 2명(C·E). `07번`의 「디바이스 중심으로 좁혀야」와 정합.
- **피부과가 기본값**: 보톡스·리프팅·울쎄라. F는 **3개월에 1회** 정기 방문.
  `10번`의 「진짜 경쟁자는 피부과(시술어 월 31만 회)」가 대면에서 확인됐다.
  → **「시술 후 홈케어」는 아직 아무도 안 건드린 각도.**
- **A의 레이저 경험**: 기미 레이저 시술 후 재발. 시술이 최종 해결이 아니라는 근거.
