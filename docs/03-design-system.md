# RIVEA(리베아) — 디자인 시스템 (토큰·타이포·컴포넌트)

> 작성일: 2026-07-28
> 방향 확정: **웜 뉴트럴 모노크롬**. UI는 무채색(잉크·화이트·웜그레이), **색은 상품 사진이 담당**.
> 근거: 무신사·지그재그·에이블리 등 커머스 앱 공통 문법 + 연구(`AI티_디자인특징`)의 "웜크림+골드 AI 기본값 회피".
> 원칙: 구조는 미니멀·직관, 온기는 **웜 그레이 + 사진 + 타이포**로. (차가운 쿨그레이 회피 → 온기 확보)

---

## 1. 토큰 아키텍처 (Brand → Alias → Mapped 3계층)

> 컴포넌트엔 **raw hex 금지**. 항상 의미 토큰(Alias)만 참조. 색 하나 바꿔도 전체 자동 반영.

### 1-A. Brand (원시값)
웜 뉴트럴 그레이 스케일 하나 + 흰색 + 기능색 1개.

| 토큰 | Hex | 비고 |
|---|---|---|
| `warm-0` | `#FFFFFF` | **페이지 배경 + 카드/표면** (배경 순수 흰색 확정) |
| `warm-100` | `#F2EEE7` | 서브틀 필/이미지 플레이스홀더/스켈레톤 |
| `warm-200` | `#E5DFD6` | 보더/디바이더 |
| `warm-300` | `#D0C8BD` | 강한 보더/호버 라인 |
| `warm-400` | `#B0A89D` | 비활성 |
| `warm-500` | `#8B8279` | 메타/캡션 텍스트 (본문엔 X) |
| `warm-700` | `#4A443E` | 보조 텍스트(본문급) |
| `warm-900` | `#1C1815` | 잉크 — 주 텍스트/주 버튼 |
| `rivea-rose` | `#C13B54` | **브랜드 시그니처 색(딥 로즈, 확정)** — 로고 워드마크 + 할인/세일 숫자. 유일 유채색. |

> - **페이지 배경은 순수 흰색(`#FFFFFF`)** 확정. 웜 오프화이트(구 warm-50) 폐기 — 지그재그처럼 화이트 베이스.
> - 온기는 배경이 아니라 **웜 그레이 텍스트/보더 + 상품 사진 + 로즈 로고**가 낸다. 웜 그레이 = R>G>B 미세 온기, 순수 회색 금지.
> - **유채색은 단 하나 `rivea-rose #C13B54`** — 로고 · 세일 숫자 · **하단 찜 하트/카운트**에만. 그 외 전부 무채색. 상품 사진이 색을 담당. (빨강 2개 혼용 방지 위해 세일색도 로즈로 통일.)

### 1-B. Alias (의미 부여) — 컴포넌트가 참조하는 층
```
--bg-page        : warm-0(#FFF) 페이지 배경 (순수 흰색)
--bg-surface     : warm-0       카드/시트/앱바
--bg-subtle      : warm-100     이미지 슬롯, 비활성 필, 스켈레톤
--brand-logo     : rivea-rose   로고 워드마크
--text-primary   : warm-900     제목/본문 강조
--text-body      : warm-700     본문 (40+ 가독성, AA 확보)
--text-secondary : warm-500     메타/보조 (캡션 한정)
--border         : warm-200     기본 헤어라인
--border-strong  : warm-300     강조 구분선/호버
--ink            : warm-900     주 액션(버튼) 바탕
--on-ink         : warm-0       잉크 위 텍스트
--price          : warm-900     판매가
--price-sale     : rivea-rose   할인율·세일가 (여기서만 유채색)
```

### 1-C. Mapped (컴포넌트 매핑) — 예시
```
버튼/Primary   bg=--ink        text=--on-ink
버튼/Secondary bg=transparent  border=--border-strong  text=--text-primary
칩(선택)       bg=--ink        text=--on-ink
칩(비선택)     bg=--bg-surface border=--border  text=--text-body
탭바 활성      icon/label=--text-primary
탭바 비활성    icon/label=--text-secondary
할인 뱃지      bg=none         text=--price-sale (숫자만)
```

## 2. 타이포그래피

### 폰트 (단일 패밀리 원칙)
- **Pretendard** 하나로 통일. 위계는 폰트를 바꾸지 말고 **크기·굵기·색**으로.
- 이유: 미니멀·클린 커머스에 최적, 한글 가독성 우수, Inter-슬롭 회피. 개성은 사진+타이포 규율로.
- 굵기는 **2~3개만**: Regular(400) / Medium(500) / Bold(700). 남발 금지.

### 스케일 (40+ 가독성 반영 — 본문 16px 이상, 12px 미만 금지)
| 역할 | 크기/굵기 | 용도 |
|---|---|---|
| Display | 28 / 700 | 히어로 헤드라인 |
| H1 | 22 / 700 | 화면 제목 |
| H2 | 18 / 600 | 섹션 제목 |
| H3 | 16 / 600 | 카드 제목/소제목 |
| Body-L | 17 / 400 | 상품 상세 본문(성분·용법) |
| Body | 16 / 400 | 기본 본문 |
| Caption | 13 / 400 | 메타(리뷰수·날짜) |
| Price | 17 / 700 | 판매가 |

- 라인하이트: 본문 1.6~1.7, 제목 1.3.
- 정렬: **문장형 대소문자**. 과한 자간/대문자 금지.

## 3. 공간·형태 시스템

- **스페이싱**: 4px 베이스. `4 · 8 · 12 · 16 · 20 · 24 · 32`. 카드 패딩 사방 균일.
- **라운드 (각진 기조 — 사용자 지시, 중요)**: 기본은 **각진 사각형**. 모서리는 끝만 **살짝 깎인 `4px`**(radius 토큰 = `4px`, 날 선 느낌만 눅임) — 둥근 사각형 금지. 입력/뱃지/칩도 `4px`(pill 금지). 상품 이미지는 각지게(`0~4px`). 풀블리드 이미지 밴드는 라운드 없음.
  - **풀블리드 규칙**: 히어로·상단 루틴 배너는 **화면 양옆 끝까지**(좌우 여백 0), **위아래 1px 선으로만** 영역 구분. 카드처럼 감싸지 않는다.
  - **베스트/상품 그리드**: 지그재그처럼 **직사각형 이미지 그리드**(각짐, 라운드 없음). 이미지 위 뱃지·하트는 오버레이.
  - **하단 CTA 버튼만 예외 — 라운드 `14~16px`**: 각진 화면 끝을 부드럽게 마무리. (장바구니/바로구매/구매하기/세트담기)
  - **하단 찜 하트**: 박스 없이 아이콘+카운트, **`rivea-rose`** 색. (박스형 각진 언어를 하단에서 풀어주는 포인트)
- **보더**: 기본 `1px solid --border`(모바일이라 0.5px 대신 1px 권장). 강조 `--border-strong`.
- **그림자**: 거의 안 씀. 필요 시 아주 옅게(하단 CTA 바 분리용). 글래스모피즘·네온 금지.
- **그리드**: 상품 목록 2열. 카드 간 gap 12.

## 4. 핵심 컴포넌트 규칙

- **상품 카드**: 이미지(1:1, `--bg-subtle`) → 브랜드명(Caption/`--text-secondary`) → 상품명(Body, 2줄 말줄임) → 가격(Price). 할인 시 정가 취소선(`--text-secondary`) + 할인율(`--price-sale`).
- **버튼**: 주 액션 1개만 Primary(잉크). 나머지 Secondary(아웃라인). 높이 ≥48px(중년 터치).
- **칩(필터/고민)**: 선택=잉크 채움, 비선택=아웃라인. 가로 스크롤.
- **하단 탭바**: 5개 균등. 활성만 진하게. 배지(장바구니 수량)는 잉크 원형.
- **하단 고정 CTA**: 상세/루틴 화면 하단 고정. 가격 + [장바구니]/[바로구매].
- **뱃지**: 신상·베스트=아웃라인 텍스트. 세일=레드 숫자. 남발 금지.
