### 고칠 곳 2 — ★5의 질문 순서 (핵심 가설이 바뀌었다)

`11번` ★5는 「순서·병용을 물어보는 고객이 있나」를 첫 질문으로 두고, 그게 나오면

```
새 1순위: "반품 사유는 주로 뭐예요?"
          → 「효과가 없어서」가 1위면 15번 §2의 72% 신호가 공급자 쪽에서 확인된다
새 2순위: "기기 사신 분들이 문의로 뭘 제일 많이 물어보세요?"
순서·병용 질문 → 뒤로 내린다 (나오면 보너스, 안 나와도 예상대로)
```

## 2. 트랙 B — 🚶 외출 (주말 중심, 총 3~4시간)

### 한 번 나가서 두 개를 얻는다

`15번` §7-1이 남긴 최대 구멍은 **40대 4명**이고, 8/15 설계 문서가 남긴 최대 구멍은
**관찰 0건**이다. 둘 다 같은 장소에서 해결된다.

**어디**: 미용실이 1순위. 파마·염색 대기가 30분 넘고, 거절 비용이 낮고, 주제가 맞다.
다음이 문화센터·요가·동네 카페.

⚠️ **40대 모집 채널은 데이터에 없다.** 이번 설문에서 카페·밴드를 적은 사람은 7명뿐이고
그중 학원·학교 커뮤니티를 적은 1명은 50대 후반이었다. 40대 4명은 전원 무응답이거나
「없음」이다. 그래서 온라인 모집 경로를 가정하지 않고 **오프라인 대면으로 간다.**

### 한 사람당 10분

```
①  종이 설문 (12pt 큰 글씨판, 이미 있음)  ─ 5분, 혼자 작성
②  폰을 건넨다. rivea-app.web.app        ─ 5분, 아무 설명 없이
③  입 닫고 본다. 어디서 멈추는지만 적는다
```

**순서가 중요하다.** 제품을 먼저 보여주면 설문 답이 오염된다 (`docs/12` 세션 설계와 동일).

⚠️ **말을 걸지 않는다.** 안내하면 관찰이 아니라 데모가 된다. `docs/12` §6-1의
*"홈화면에 딱 40·50대를 위한 앱이라는 게 잘 모르겠다"*가 무개입 상태에서 재현되는지가 핵심이다.

### 목표

- **관찰 3명 이상** (모르는 사람. 재회 불필요)
- **40대 설문 8명** → 누적 12명. 50대는 더 받아도 88%·72%가 안 바뀐다 (`15번` §7-1)

## 7. 콜드 스타트 순서 (9/2와 무관, 기록용)

전화 결과가 P3 확정이면 이 순서로 간다. 양쪽을 동시에 채우지 않는다.

```
① 상품 정보 (계약 0건)        ← 이미 있다. catalog.ts 실측 25종
② 안내 + 밖으로 내보내기       ← 결제는 우리가 안 받는다. 「딱히 없다」 41%가 허락해줬다
                                쿠팡파트너스(개인 가입 가능) 또는 브랜드 공식몰
③ 계측                        ← C-1. 클릭 로그가 협상 재료다
④ 딸 경로로 트래픽             ← 자녀 지정 요청 55%. 딸은 30대·인스타·광고 단가가 싸다
                                /gift가 이미 3단계로 구현돼 있다
⑤ 로그를 들고 입점 협상        ← "당신 제품에 M명 보냈습니다"
```

**좁게 시작한다**: 7개 고민 전부가 아니라 **기미·잡티 하나.**
`07번` 문헌에서 40대 77.2%로 1위이고, 이번 설문 검색어 원문에 「기미」·「PDRN기미앰플」·
「미백크림」이 반복되고, **「돈이 아깝다」에 기미크림이 3번 나온다**
(*"기미크림 호전되는 기미가 없었다"*). **이미 돈을 쓰고 실패한 카테고리가 진입점으로 가장 좋다.**
