## 0. 요약 — 세 줄

1. **「피부관리」는 쓰면 안 된다.** 검색량의 86%가 「피부관리샵·피부관리실」, 즉 오프라인 업소다.
2. **「뷰티」도 카테고리어로 존재하지 않는다.** 87%가 「뷰티디바이스」라는 복합명사 하나다.
3. **그런데 이름은 이 조사에서 세 번째로 중요한 문제였다.**
   **퀸잇이 이미 4050 뷰티를 하고 있고, 내세우는 차별점이 우리와 같다.** → §3

## 1. 실측 — 카테고리 단어별 검색량

| 단어 | 포함 키워드 수 | 월 검색 합계 | 실제로 무슨 뜻인가 |
|---|---:|---:|---|
| 피부 | 92 | 51,705 | 증상·상태어의 접두사 (피부하얘지는법, 피부요철) |
| **뷰티** | 20 | **27,035** | **87%가 「뷰티디바이스」 계열** |
| **화장품** | 90 | **22,715** | **전부 수식어+화장품** (기미화장품, 레티놀화장품) |
| **피부관리** | 9 | **9,660** | **86%가 「피부관리샵·피부관리실」= 오프라인 업소** |
| 케어 | 25 | 2,965 | 접미사로만 |

| 스킨케어 | 6 | 735 | 거의 안 침 |
| 홈케어 | 6 | 495 | 거의 안 침 |

### 1-1. 「뷰티」 27,035회의 실체

```
뷰티디바이스          21,400  ┐
뷰티디바이스추천        1,790  ├ 23,510 = 87%  ← 「디바이스」에 붙은 수식어
뷰티디바이스비교          180  │
홈케어뷰티디바이스         140  ┘
바이탈뷰티*             2,850     ← 아모레 브랜드명 (먹는 콜라겐)
이너뷰티*                700
```

**「뷰티」 단독은 이 데이터셋에 없다.** 디바이스에 붙거나 브랜드명이다.

### 1-2. 「피부관리」 9,660회의 실체

```
피부관리샵     6,040  ┐
피부관리실     2,190  ├ 8,310 = 86%  ← 전부 오프라인 업소
남자피부관리샵     80  ┘
```

→ **「피부관리 이커머스」라고 하면 관리샵 예약 서비스로 읽힌다.** 쓰지 말 것.

### 1-3. ⚠️ 이 데이터의 한계 (반드시 같이 읽을 것)

이 파일들은 **연관키워드 조회 결과**라서 **시드어(단독 「뷰티」·「화장품」·「피부관리」)가 결과에 포함되지 않는다.**
표의 「정확일치 0」은 전부 이 때문이며, **「사람들이 그 단어를 안 친다」는 증거가 아니다.**

여기서 말할 수 있는 건 **구성(composition)뿐**이다:
「뷰티」라는 글자가 등장할 때 87%는 디바이스이고, 「피부관리」가 등장할 때 86%는 업소다.
단독어의 절대 검색량을 알려면 네이버 도구에서 세 단어를 **시드로 직접** 조회해야 한다. (§6 할 일)

## 2. 그래서 이름을 어떻게 할 것인가

**질문을 둘로 갈라야 한다. 섞으면 틀린 답이 나온다.**

### 2-1. 검색 진입어 → 셋 다 아니다

`10번` 결론 그대로다. 진입은 카테고리어가 아니라 **증상어·성분어·시술어**로 일어난다.

| 진입어 | 월 검색 |
|---|---:|
| 리쥬란 | 63,900 |
| 리포좀비타민C | 41,740 |
| 히알루론산 | 39,300 |
| 기미크림 | 20,080 |
| (대조) 40대화장품 | 260 |
| (대조) 50대화장품 | 280 |

→ **SEO·광고 카피에 카테고리어를 쓰는 건 어느 쪽을 골라도 무의미하다.** 고민어·성분어를 쓴다.

### 2-2. 응답자 대면 언어(설문·앱 카피) → 「화장품」 유지

**검색어 데이터를 여기에 그대로 적용하면 안 된다.** 검색창에 치는 말과 대화에서 쓰는 말은 다르다.
이 판단의 근거는 키워드가 아니라 `12번` 인터뷰다.

- 6명 전원이 「화장품」이라고 말했다 (B "톤에 맞춰서 화장품을 사주기도", D "화장품 검사 어플 화해")
- **「뷰티」나 「피부관리」라고 말한 사람은 0명이다**

→ 설문지와 앱 카피는 **「화장품」**. 사용자가 실제로 쓰는 단어다.

### 2-3. 사업 규정(IR·내부) → 「4050 여성 스킨케어 커머스」

- **「피부관리」 금지** — 관리샵으로 읽힌다 (§1-2)
- **「뷰티」 비추천** — 메이크업·헤어·향수까지 약속하게 된다. 우리가 안 하는 것이고,
  퀸잇 뷰티 거래액의 60%도 결국 스킨케어다
- **「스킨케어」 권장** — 검색량은 작지만(735) 이건 **진입어가 아니라 규정어**다.
  오해가 없고, 퀸잇도 자사 설명에 이 단어를 쓴다

### 2-4. 그런데 사용자 지적은 맞았다 — 대상이 좁다

「화장품」이라는 **단어**는 유지하되, 설문이 **묻는 대상**은 넓혀야 한다.
지금 A파트는 화장품만 물어서 **기기와 시술이 구매 대상에서 빠져 있다.**
인터뷰에서 30–40만원대 기기 사용자가 2명(`12번 §7`), 시술어 검색이 월 31만 회(`10번 §4`)인데
정작 "최근에 뭘 샀나"에서 그게 안 잡힌다. → §6 할 일

## 3. ★ 이름보다 큰 것 — 퀸잇이 이미 우리 자리에 있다

### 3-1. 숫자

2025년 상반기, 퀸잇 뷰티 카테고리:

| 지표 | 증가율 |
|---|---:|
| 거래액 | **+95%** |
| 주문 수 | +118% |
| 주문 고객 수 | +148% |
| 뷰티 브랜드 수 | +249% |
| 센텔리안24 **기기** 거래액 | **+1,190%** |

- **스킨케어가 뷰티 거래액의 60%.** 상위 카테고리는 에센스·앰플·아이크림
- 취급: 센텔리안24, 미샤, 에뛰드, 설화수

### 3-2. 퀸잇이 내세우는 차별점 — 우리 것과 같다

퀸잇이 공식적으로 밝힌 세 가지:

| 퀸잇이 말하는 것 | RIVEA에서 대응하는 것 |
|---|---|
| 「노화·탄력·보습·기미 등 **피부 고민별** 기능성 제품 정보」 | **「고민으로 찾기」** |
| 「4050 맞춤형 리뷰 추천 기능과 **전문 큐레이션**」 | 온보딩 기반 추천 |
| 「**안티에이징 전문성**」 | 제품 구성 전반 |
| 히알루론산·줄기세포·콜라겐 등 **성분 기반 테마** | 성분 정보 |
| **디바이스 취급** | 디바이스 카테고리 |

**「4050 전용 + 고민별 큐레이션」은 이미 점유된 포지션이다.**
그리고 퀸잇은 `12번`에서 **인지율 6/6**, `10번`에서 **월 16.7만 검색**이다. 인지도 싸움이 안 된다.

### 3-3. 그럼 우리한테 뭐가 남았나

퀸잇에서 **확인되지 않은** 것 — 즉 아직 빈 자리일 가능성:

| 빈 자리 | 근거 |
|---|---|
| **루틴·순서** (1단계·2단계 묶음, 바르는 순서) | `12번 §2-2` 3방향 독립 언급. 퀸잇은 낱개 상품 큐레이션 |
| **저장·재발견** (봐둔 것 다시 찾기) | `12번 §2-1` 신규 발견. 어느 플랫폼도 안 함 |
| **시술 후 홈케어** | `10번 §4` 시술어 월 31만. 퀸잇 설명에 없음 |

⚠️ **「검색으로 안 나왔다」는 「없다」의 약한 증거다.**
퀸잇 앱을 직접 깔아서 루틴 기능 유무를 확인하기 전까지 이 세 개를 빈 자리로 확정하지 말 것. (§6 할 일)

## 4. 결론

| 쓰이는 자리 | 답 |
|---|---|
| 검색·광고 진입어 | 카테고리어를 쓰지 않는다. **고민어·성분어·시술어** |
| 설문지·앱 카피 | **「화장품」** (인터뷰 6/6이 쓴 단어) |
| 사업 규정·IR | **「4050 여성 스킨케어 커머스」** |
| 절대 금지 | **「피부관리」** — 오프라인 관리샵으로 읽힌다 |

**단, 이름은 이 조사에서 제일 작은 문제였다.** §3이 본론이다.

## 5. 이 문서가 뒤집는 것

- `12번 §2-5` 「퀸잇 인지 = 중년 전용 포지션이 통한다는 증거」 →
  **여전히 맞지만 절반이다.** 통한다는 증거이자 **이미 점유됐다는 증거**다.
- 설문 v2의 퀸잇 문항이 「**옷 파는** 퀸잇」이라고 규정하고 있었다 → **사실과 다르다. 수정함.**
  인지도만 묻지 말고 **「거기서 화장품을 사봤는지」**를 받아야 직접 경쟁 지표가 나온다. (문항 추가함)
