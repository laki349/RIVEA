### 1. How to Use Claude Skills as a Designer
`256,298회` · Griffin Wooldridge · 9:30 · 2026-03-09
https://youtube.com/watch?v=Iup1WlUyj9M

디자이너가 알아야 할 클로드 스킬 총정리. 카드뉴스 퀄의 기반이 되는 스킬 5종.
- **frontend-design** (최중요): 코드 한 줄 쓰기 전에 목적·톤·제약·차별화 4가지를 강제로 사고하게 만든다. `front-end aesthetics guidelines` 섹션이 시니어 프로덕트 디자이너가 쓴 것처럼 타이포·컬러·모션·공간구성·분위기를 다룬다. **AI 슬롭(보라 그라데이션, 흰 배경 라운드 카드, Inter 남용)을 명시적으로 금지**.
- **implement-design** (Figma 공식): Figma URL 붙이면 file key·node ID 파싱 → Figma MCP로 레이아웃/오토레이아웃/타이포/컬러/스페이싱 토큰 전부 읽고 → 스크린샷을 시각 참조로 확보 → 에셋 다운로드 → 코드 생성. 끝에 레이아웃·타이포·컬러·인터랙션·반응형·접근성 검증 체크리스트를 스크린샷과 대조 실행. **Figma MCP 연결 필수.**
- **theme-factory**: 컬러+폰트 페어링 완성된 프로 테마 10종. 슬라이드·문서·웹·대시보드에 그대로 적용.
- **brand-guidelines**: 브랜드 규칙(hex·폰트 스택·여백·로고 사용·톤)을 모든 산출물에 자동 강제. Anthropic 브랜드가 기본값이지만 **템플릿으로 쓰고 자기 토큰으로 교체**하는 게 요점. 디자인 시스템 담당자 없는 소규모 팀에 특히 강력, 비디자이너에게 공유하면 그들 결과물도 브랜드를 따른다.
- **canvas-design**: UI가 아니라 포스터·그래픽 등 실제 PNG/PDF 제작. 2단계 — ①시각적 무브먼트를 정의하는 "디자인 철학" 문서 작성 ②그 철학을 캔버스에 실행. 소셜 그래픽에 유용.
- **skill-creator**: 없는 스킬은 만든다. 클로드가 엣지케이스·입출력 형식을 인터뷰 → SKILL.md 초안 → 테스트 프롬프트 작성·실행·결과 제시 → 피드백 반복. `.skill` 파일로 패키징해 공유.

### 3. Claude Code to Figma
`143,792회` · **Figma 공식** · 3:20 · 2026-02-17
https://youtube.com/watch?v=riFFyTRljic

Figma MCP 서버의 `Claude Code to Figma` 기능 공식 발표. 짧지만 원리가 가장 명확.
- 문제 정의: 코드는 빨리 "실물"에 도달하지만 **탐색 단계를 건너뛰게 만든다**. 코드로 탐색하려면 브랜치·피처플래그·변수/상태 배선이 필요하고, 결과물은 내 노트북에만 있어서 공유가 안 된다. 피드백은 스크린샷·녹화로 오간다. 코드 결정은 본질적으로 단일 파일·순차적이라 **수평적 탐색이 막힌다**.

- ⚠️ **반드시 클로드 코드 공식 문서(서브에이전트 / 에이전트 스킬 페이지)를 프롬프트에 복사해 넣고 "공식 가이드라인을 참고해줘"라고 명시.** 안 하면 클로드가 "스킬이 뭘까" 상상해서 만든다. 실제로 프롬프트도 클로드에게 공식 문서를 함께 탐구하게 해서 만든 결과물.
- 모델 배분: 기본 Sonnet, **고품질 글이 필요한 뉴스레터 등은 Opus로 교체**.
- Nano Banana 연동: Google AI Studio > Get API Key로 키 발급 → 클로드에 "이 API 키로 Gemini 3 Pro Image 생성 설정해줘" + **AI Studio의 API 퀵스타트 Python 코드 샘플을 함께 붙여넣기**. 기본 모델이 이미지 모델이 아니므로 `gemini-3-pro-image-preview`로 명시 지정 필요.
- ⚠️ API 키가 Python 파일에 들어가므로 위치 파악·관리 필수. 배포용 SKILL.md에는 환경변수로 분리.
- 결과 평가: 카드뉴스는 폰트까지 좋고 인포그래픽·CTA까지 잘 나옴. 썸네일은 1024×768 비율 미준수·로고 깨짐 → 프롬프트 보정 필요. 쇼츠는 추출만 되고 편집은 안 됨, 자막 인식 정확도를 위해 medium/large 모델 권장.
- 저작권 주의: 남의 유튜브 무단 사용 금지, 자기 콘텐츠나 권리 확보된 것만.

### B4. 클로드 코드 스킬로 인스타 카드뉴스 자동 생성
`17,524회` · 짐코딩 · 17:03 · 2026-04-21
https://youtube.com/watch?v=501KRO5QSXM

**카드뉴스 자동화 전 과정을 스킬로 굳히는 가장 정석적인 편.** (A그룹에도 넣을 만하지만 자동화 성격이 강해 B그룹에 배치)
- 방식: **HTML 파일 생성 → Playwright(browser control)로 캡처 → 이미지.**
- 왜 HTML/CSS인가 (3가지): ①AI 생성 이미지는 완전 제어 불가, HTML/CSS는 **폰트 크기·색상·간격을 1px / 특정 색상값 단위로 정밀 제어** ②템플릿 한 번 만들면 100장·1000장이 동일 퀄 ③클로드 구독만으로 **무료**. HTML/CSS를 몰라도 클로드가 아주 잘 처리한다.
- 원칙: **즉시 구현 금지 → 컨텍스트 수집 → plan → 구현.** 개발뿐 아니라 마케팅·유튜브 기획·카드뉴스 전부 동일.
- 1) 소재 수집: 대상 URL을 주고 "링크 전문을 한국어로 번역해 저장. 원문 문장 구조와 순서 정확히 유지, 초보도 이해할 수 있게 단순하게" → `source/` 저장. (카드뉴스만 만들 거면 **영어 그대로 수집이 토큰 절약**.)
- 2) 요구사항: **4:5 = 1080×1350**, 순수 HTML/CSS, **커버 1 + 본문 N + CTA 1**. 기존 인스타 커버를 캡처해 프롬프트에 첨부(헤더/푸터는 고정, 본문 영역은 내용에 맞게), CTA 이미지도 캡처 첨부. 필요 시 로고 등 이미지 첨부(직접 or 클로드가 수집).
- 3) plan mode: 질문 몇 개 받고 답변(내러티브 옵션 선택, 8장으로) → **레이아웃·컬러 토큰·폰트·카드별 내용이 전부 명시된 plan** 확인. 4단계에서 피드백으로 수정 가능. 복잡하면 **Ultra Plan**. plan 파일은 Cmd/Ctrl+클릭 또는 Ctrl+G로 열어 직접 편집(터미널 깨지면 **Warp** 권장). → bypass permission 모드로 실행.
- 4) 수정: 프롬프트로도 되고, **코드 에디터에서 직접 수정이 더 빠를 때가 많다**(예: cover title 폰트 크기를 줄여 한 글자 줄바꿈 제거). 한 번 고생하면 그게 템플릿이 된다.
- 5) 이미지화: "Playwright CLI로 HTML을 이미지로 변환" → 커버~본문~CTA 전부 생성.
- 6) **CLAUDE.md 타이밍**: 이 카드뉴스는 `/init`도 CLAUDE.md도 없이 만들었다. 이유는 **새로 만든 프로젝트라 분석할 게 없었기 때문.** 미리 개요/맥락을 써두면 도움은 되지만, 카드뉴스는 단순 작업이라 일부러 안 만들었다. **복잡한 작업을 할 때 / 클로드가 좀 멍청해질 때 기록한다. 과설계하면 뭘 써야 할지 몰라 시작조차 어려워진다.**
- 7) 스킬화: `/init`으로 CLAUDE.md 생성 → clear → **Skill Creator**(Marketplace > Official Claude Plugins, User Scope 설치 후 reload) → "현재 카드뉴스를 템플릿으로, 다음 카드뉴스도 같은 디자인 스타일로 만드는 스킬" → Project Scope 설치. **테스트 케이스 2~3개로 트리거를 검증하며 만드는 게 좋다.**
- 8) 구조 리팩터링: `episodes/YYMMDD_주제/` 로 회차별 관리, `card.css`·로고 등 공유 자원은 루트.
- 9) ⚠️ **스킬 생성 후 세션 재시작 필요** — 안 하면 감지되지 않는다. 재시작 후 `/card-news`로 즉시 사용, HTML만 먼저 생성 후 이미지화 분리 가능. 레이아웃이 마음에 안 들면 **스킬 자체를 수정**한다.

## 이 프로젝트(RIVEA)에 적용한다면

리서치 결론을 그대로 옮기면 이렇게 된다.

1. **[docs/03-design-system.md](03-design-system.md)를 카드뉴스용 `style.md`로 파생.** 각진 + 풀블리드 + 웜 뉴트럴 모노크롬 디자인 언어를 컬러/폰트/여백/레이아웃 규칙으로 명시. 브랜드 일관성 장치는 이미 절반 이상 있다.
2. **HTML/CSS + Playwright 캡처 경로 채택.** 1080×1350(4:5), 커버 1 + 본문 N + CTA 1. 이미지 생성 모델은 커버에만(하이브리드).
3. **AI 슬롭 금지 조항을 style.md에 명문화** — 보라 그라데이션·흰 배경 라운드 카드 금지는 이미 우리 디자인 언어(각진)와 충돌하지 않는다. 폰트는 Pretendard 계열 고정.
4. **`episodes/YYMMDD_주제/` 구조 + `/card-news` 스킬**로 굳히기. 첫 회차만 고생하고 이후는 주제 한 줄.
5. **40대+ 여성 홈케어 니치 레퍼런스 라이브러리부터 20~30분 수집.** 니치 밖(지역 매거진·에디토리얼)도 함께 봐야 차별화된다.
